A practical server handbook.

An independent guide for Java Edition communities, not an official service or a hosting offer.

Pick one server family

Vanilla keeps the smallest moving parts. Paper-compatible servers add plugin choices; modded worlds need compatible versions on every client. Keep a list of the exact files and versions used.

Distance is a capacity setting

Simulation distance affects the area that keeps ticking. View distance affects chunks sent to players. Lower them before buying more memory, and compare tick time while friends explore in different directions.

A backup is a restore plan

Stop the server or use its supported save procedure before taking a consistent copy. Keep backups away from the world directory. Test a restore into a separate folder before you need it.

Keep the join boundary clear

Leave online-mode enabled, use an allowlist for a private group and keep administrative access separate. The planner generates settings, not a reachable server. Review all settings before deployment.

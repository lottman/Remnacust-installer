# 1.2.144

Нода с собственным доменом получает один из 20 случайных многостраничных сайтов вместо страницы-заглушки. Темы: обувь, Minecraft, кофе, выпечка, велосипеды, растения, архитектура, керамика, походы, искусство, книги, музыка, мебель, питомцы, путешествия, тренировки, программирование, астрономия, настольные игры и веб-хостинг.

В каждом варианте есть тематические страницы, полезный инструмент, страница о сайте, собственная 404 и локальная графика. Внешние CDN, шрифтовые службы и аналитика не используются. Сайты статические; заказы, оплата и создание игровых серверов требуют отдельной службы владельца.

- Вариант выбирается один раз. Обновление, перезапуск и продление сертификата сохраняют сайт и авторские правки.
- `configure-node-site` выбирает другой случайный вариант после подтверждения, сохраняя прежние файлы в `backups/node-sites/`. Xray не перезапускается.
- Работающий Nginx пересоздаётся и проверяется. При ошибке выполняется защищённый откат, в том числе для сайта с авторскими правками. Остановленный Nginx не запускается.
- Служебные записи и резервные копии хранятся вне публичного каталога. Проверяются пути, символьные и жёсткие ссылки, права и целостность файлов.
- Каталог входит в проверяемый комплект установщика. Формат сохранён совместимым со старыми установщиками, которые готовят новый скрипт для обновления из панели.

[Настройка selfsteal](../NODE-SELFSTEAL.md) · [English guide](../NODE-SELFSTEAL.en.md) · [Редактирование исходников](../../sites/README.md).

Комплект использует опубликованные Panel / Page **1.1.7.100**, Node **1.1.26** и Core **1.1.16**. Их версии и закреплённые исходники не изменены. Выпуск не устанавливается на работающие серверы автоматически.

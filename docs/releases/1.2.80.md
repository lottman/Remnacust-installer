# 1.2.80

Панель и страница подписки 1.1.7.46, нода 1.1.18. Core/WASM остаётся 1.1.11. Миграций БД нет.

- Защита плагина проверяет необходимые возможности ноды до изменения активной конфигурации. Недоступный nftables/NET_ADMIN больше не выглядит успешным применением. Панель учитывает отрицательное подтверждение назначения плагина; новые ноды объявляют строгую семантику подтверждений. Ответ старой ноды об уже отсутствующем плагине остаётся совместимым.
- Torrent blocker применяет исключения владельца ко всем его персональным ключам устройства/хоста. Отчёт сохраняется по числовому ID пользователя, исходная Xray-идентичность остаётся в технических данных.
- Обход активных сессий пользователя отличает успешный пустой результат от отказа всех нод. Частичный обход сохраняет найденные подключения и показывает названия недоступных нод. Предупреждение локализовано на RU/EN/FA/ZH и использует общую тему панели.
- Ограничение хоста DENY сохраняет ручные и geofile-правила Xray JSON, балансеры и параметры маршрутизации. Строгая семантика ALLOW_ONLY сохранена.
- Импорт SRS версий 1–4 проверяет структуру всех записей, типы, длины, вложенность, доменные деревья и диапазоны IP. Неизвестные типы, обрезанные и лишние данные отвергаются; ограничения размера и распаковки сохранены.
- Параллельный импорт одинаковых geofiles между API-процессами возвращает одну запись. Добавлена проверка четырёх процессов с PostgreSQL в CI.
- Синхронизированы контракты, OpenAPI, справочник и переводы. Временные стенды не входят в образы.

Обновите ноды командой `sudo remnacust upgrade-node --version 1.2.80`, затем панель: `sudo remnacust upgrade-panel --version 1.2.80`. Строгая проверка возможностей защиты требует ноды 1.1.18; обновление одной панели не меняет старый агент. Остальные компоненты сохраняют существующие настройки и данные.

Структурная проверка ruleset не заменяет проверку совместимости конкретной версии клиентского приложения. Опрос сессий не гарантирует обнаружение коротких подключений между снимками.

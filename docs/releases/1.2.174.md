# 1.2.174

Комплект включает Panel/Page 1.1.7.126, Node 1.1.37 и Core 1.1.22 на официальной основе Xray v26.11.9.

В панели адреса управления нодой объединены в упорядоченный список с поддержкой IPv4, IPv6 и доменных имён. Недоступный адрес заменяется следующим включённым адресом. Сохранённые адреса можно отключать; отключение всех адресов приостанавливает управление нодой со стороны панели, сохраняя работу её VPN. Настроенный SOCKS5 остаётся обязательным для управления: отказ прокси не приводит к прямому подключению.

Добавлены колонка Proxy, уточнённые состояния доступности и распределение новых соединений между доступными участниками пула автовыбора. Выбор стратегии учитывает возможности формата подписки; sing-box использует явно указанный запасной режим urltest. Открытые соединения сохраняют свой сервер.

Xera HTTP поддерживает необязательную адаптацию в трёх режимах с минимальной и максимальной границами активных HTTP-запросов. Настройки доступны в редакторе панели. Адаптация требует Core 1.1.22 или новее у клиента; обновление панели не обновляет приложения пользователей. Она не гарантирует невидимость для DPI или доступность заблокированного адреса.

Node ограничивает ожидание операций управления ядром и согласует изменения конфигурации, пользователей и сбор статистики. XDRIVE ограничивает накопление недоставленных сегментов и очищает данные завершённых сеансов с повтором после ошибок хранилища. Обновлены зависимости и документация.

Установка и обновление панели не заменяют ноды автоматически. Для перехода существующей Remnawave Node используйте отдельную команду миграции из README после проверки выбранного контейнера и сохранённых настроек.

## English

This bundle includes Panel/Page 1.1.7.126, Node 1.1.37 and Core 1.1.22 based on the official Xray v26.11.9 release.

Node control addresses form an ordered list supporting IPv4, IPv6 and hostnames. An unavailable address gives way to the next enabled address. Saved addresses can be disabled; disabling every address pauses panel management while the node's VPN continues running. A configured SOCKS5 proxy remains mandatory for management: proxy failure never triggers a direct connection.

Adds a Proxy column, clearer availability states and distribution of new connections across available autoselect pool members. Strategy selection respects subscription-format capabilities; sing-box uses an explicitly described urltest fallback. Existing connections keep their server.

Xera HTTP offers optional adaptation with three modes and minimum/maximum active HTTP-request bounds, configurable in the panel editor. Adaptation requires Core 1.1.22 or later in the client; updating the panel does not update user applications. It cannot guarantee DPI invisibility or reachability of a blocked address.

Node bounds waits for core management and coordinates configuration changes, user mutations and statistics collection. XDRIVE bounds undelivered segments and retries closed-session cleanup after storage errors. Dependencies and documentation are updated.

Installing or updating the panel does not automatically replace nodes. Migrate an existing Remnawave Node separately using the README command after checking the chosen container and saved settings.

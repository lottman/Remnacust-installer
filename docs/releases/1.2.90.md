# 1.2.90

Панель и страница подписки **1.1.7.56**. Нода **1.1.19**, Core/WASM **1.1.11** без изменения. Новых миграций БД нет.

- Автовыбор сохраняет границы UUID и исходный фильтр при переключении группового regex/recipient-отбора на выбор при подключении. Кнопка и выбор режима работают с одним черновиком. Недоступные и посторонние хосты не добавляются.
- При переходе ручной клиентской группы в автоматическую задаются URL и интервал проверки доступности. Собственные параметры сохраняются. Пояснения обновлены на RU/EN/FA/ZH.
- Постоянный TCP-вход проверяет DNS и нормализованные IP обоих концов, чтобы конечный сервер не указывал обратно на вход. Установщик корректно проверяет IPv4-mapped IPv6 на Ubuntu, запрещает scope ID и дублирующиеся адреса.
- Скачиваемые руководства содержат описания полей. Проверка документации обнаруживает неполную генерацию.
- Добавлены сравнения GUI и ручного кода через генераторы Xray, Mihomo, Clash, Stash и sing-box. Проверены реальные API, PostgreSQL, Valkey, пакетные firewall-правила, HAProxy и приоритетное переключение настоящего ядра в изолированной сети.

Смена серверов без обновления подписки использует отдельный постоянный TCP-вход. Он обслуживает новые соединения, не мигрирует открытые соединения и не поддерживает UDP. Изменение адресов или ключей обычного клиентского пула требует обновления подписки. Проверки не заменяют испытания каждой версии стороннего приложения и рабочего VPN-трафика.

Обновление: `sudo remnacust upgrade-panel --version 1.2.90`. Выпуск готовых образов не обновляет рабочие серверы автоматически.

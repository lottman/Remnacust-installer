# 1.2.74

Панель и страница подписки 1.1.7.43, Node 1.1.17. Перенесены только опубликованные официальные обновления: Backend/Frontend 3.4.7 (включая 3.4.6), Node 3.4.3 и Subscription Page 8.0.1. Страница подписки подтверждена официальным тегом и опубликованными Docker-образами amd64/arm64; коммиты веток разработки после тегов не включались.

Образы используют опубликованный Node.js 24.22.1. Исправлено получение публичных ключей X25519 для REALITY и VLESS encryption: используется официальный helper Noble Curves вместо JWK с пустой координатой x. Приватные ключи не меняются. Некорректный ключ одного inbound не мешает обработке остальных. Массовое удаление пользователей по статусу использует параметризованный SQL с ограничением количества.

На странице подписки добавлена поддержка `{{INCY_CRYPT1_LINK}}`. Подстановка создаёт ссылку импорта INCY из исходного URL подписки. Существующие обычные URL, Happ-ссылки, шаблоны и оформление сохраняются.

Xray не менялся: Core/WASM 1.1.11 на официальном опубликованном v26.10.21 уже актуален. SDK 0.17.0 и geocheck 0.3.0 также не менялись. Сохраняются лимиты пользователя и устройства, динамическое распределение скорости, автономные квоты и существующие ключи. Миграций БД в этом выпуске нет. Требования XDRIVE из 1.2.73 сохраняются.

Обновление: `sudo remnacust upgrade-panel --version 1.2.74`, затем на нодах `sudo remnacust upgrade-node --version 1.2.74`.

Официальные источники: [Backend 3.4.7](https://github.com/remnawave/backend/releases/tag/3.4.7), [Frontend 3.4.7](https://github.com/remnawave/frontend/releases/tag/3.4.7), [Node 3.4.3](https://github.com/remnawave/node/releases/tag/3.4.3), [публикация Subscription Page 8.0.1](https://github.com/remnawave/subscription-page/actions/runs/39722347736).

# 1.2.159

Комплект: Panel/Page **1.1.7.112**, Node **1.1.29**, Core/WASM **1.1.18**, Xray **26.11.9**.

- GEO включается отдельно в меню ⋯ каждого шаблона. Состояние видно рядом с меню; новые шаблоны выключены, существующие сохраняют прежнее состояние. Общего переключателя больше нет. JSON на базовом пути остаётся обязательным; ручные правила администратора сохраняются.
- Порог 1–250 000 условий, по умолчанию 20 000 включительно, проверяется отдельно для каждого итогового профиля хоста. Соседние профили не суммируются; только большой профиль переходит на DAT. Защитные бюджеты размера остаются.
- Исправлено лишнее чтение полного каталога шаблонов при запросах подписки: ограниченный кэш с поколениями и объединением одновременных загрузок не заменяет проверку пользовательского доступа, HWID или квот.
- Иконки больше не увеличиваются при нажатии: эффекты работают с деталями SVG и учитывают уменьшение движения. Документация и локализация обновлены на RU/EN/FA/ZH, добавлен пример назначения автовыбора.
- Миграция 202 проверена вместе с остальными миграциями на PostgreSQL 14.24/15.19/16.15/17.11/18.6 под владельцем без superuser. Сверены уже перенесённые исправления безопасности upstream. Обновите отдельно размещённую страницу подписки вместе с панелью; сохраняйте секреты и резервные копии.

- Ошибка ссылки на отсутствующий выход в одном JSON-профиле больше не обрывает выдачу всех исправных профилей. Некорректный профиль целиком исключается без обхода ограничений; причина видна в предпросмотре администратора. Если исправных профилей нет, ошибка сохраняется.
- Региональные назначения ограничивают только доказуемо неиспользуемые пулы; просмотр назначений доступен в карточке хоста. Явные настройки проверок и резерва сохраняются.

## English

Panel/Page **1.1.7.112**, Node **1.1.29**, Core/WASM **1.1.18**, Xray **26.11.9**. Enable geofiles per template through its menu; visible normal/crossed-out icons show the state. Existing state is preserved, new templates default to off. The inline threshold applies per final profile, and only oversized profiles switch to DAT. Independent safety budgets remain. A bounded generation-aware catalogue cache coalesces full-template reads without caching user authorization, HWID or quotas. Icon detail animations replace press scaling and respect reduced motion. Migration 202 and concurrency checks passed on five PostgreSQL majors with restricted owners. Update separately hosted subscription pages along with the panel; keep secrets and backups unchanged.

Invalid route references isolate only the affected JSON profile, without rewriting administrator settings or bypassing restrictions. Healthy profiles remain available; all-invalid responses still fail. Administrator previews report the affected host. Scoped pool assignments and configured fallback probes are preserved.

Удаление хоста из карточки больше не вызывает повторный запрос удалённого хоста и ложную ошибку «Host not found». Ошибки самого удаления сохраняются; список и остальные хосты обновляются.

Successful host-card deletion no longer refetches the deleted resource. Actual DELETE errors retain the card and its data.

## Финальные исправления

- Анимации иконок ограничены sidebar; Ctrl/Cmd+F и F3 в хостах и нодах открывают поиск панели.
- Метаданные политик хостов читают ключи одним проходом, без кеширования авторизации.
- Главная сохраняет общую кнопку обновления всех источников статистики; блок БД и дополнительная диагностика подключения ноды удалены из интерфейса.
- Core 1.1.18 передаёт версию совместимости REALITY 26.11.9 вместо номера продукта 1.1.x; проверки ключей и заданных серверных границ сохранены. Штатный Xray остаётся отдельным binary.

Sidebar-only icon feedback, page-search shortcuts, bounded host metadata scans and an all-source Home refresh are included. Core 1.1.18 fixes the REALITY wire-version mismatch without weakening authentication or explicit version bounds.

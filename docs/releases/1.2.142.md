# 1.2.142

Согласованный комплект: Panel/Page **1.1.7.102**, Node **1.1.26**, Core/WASM **1.1.16** на основе Xray v26.10.31.

- В панель добавлены редактирование и независимые копии геофайлов, собственные правила адресов, проверки регулярных выражений и ссылок на категории.
- Исправлены устаревшие шаблоны после сохранения при сбое Redis, обработка больших списков и приватность путей в ошибках. Проверены 196 миграций PostgreSQL 14–18 под владельцем БД без superuser.
- Node и Core в этом комплекте сохраняют прежние стабильные версии. Новые инструменты редактора не меняют протокол связи панели с нодой.
- Образы amd64 и arm64 собираются отдельно. Установщик получает Latest и проверяет закреплённые исходники, версии и контрольные суммы; major-версия существующей БД не меняется автоматически.

Публикация комплекта не устанавливает обновление на рабочий сервер. Перед обновлением сохраните БД, `.env`, `APP_SECRET` и постоянные тома.

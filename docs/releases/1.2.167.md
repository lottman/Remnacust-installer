# 1.2.167

- Комплект: Panel/Page 1.1.7.119, Node 1.1.31, Core 1.1.19 / Xray v26.11.9.
- Панель восстанавливает стандартные источники GeoIP/GeoSite в ранее выданных профилях Happ/INCY после отключения всех кастомных DAT в подписке или возврата всех профилей к обычным правилам. Ручные источники администратора и ещё используемые DAT не заменяются. Новая подписка без истории не получает лишнее скачивание.
- После обновления панели обновите подписку, дождитесь успешного скачивания стандартных файлов в приложении и переподключитесь. Если серверная история профиля или устройства потеряна либо имя изменилось, используйте восстановление геофайлов в приложении.
- Образы amd64/arm64, исходники, инструкции и документация образуют согласованный комплект. Новых миграций нет. Обновление панели сохраняет настройки, существующие образ БД и тома; удалённые ноды и отдельные сайты подписки обновляются отдельно.

## English

Pins Panel/Page 1.1.7.119, Node 1.1.31 and Core 1.1.19 / Xray v26.11.9. The panel restores standard GeoIP/GeoSite sources in previously issued Happ/INCY profiles after all custom DAT files are disabled or all profiles return to inline rules. Explicit administrator sources and DAT files still in use retain precedence; fresh subscriptions without history receive no unnecessary downloads. Refresh the subscription, wait for successful standard-file downloads and reconnect. Restore geofiles in the app if server-side profile/device history is missing or the name changed. The amd64/arm64 images, sources and documentation form a matching cohort. No new migration; panel upgrades preserve settings, existing database images and volumes. Remote nodes and separate subscription websites require separate updates.

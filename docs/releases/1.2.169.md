# 1.2.169

Согласованный комплект: Panel/Page 1.1.7.121, Node 1.1.32, Core 1.1.19 / Xray 26.11.9.

Добавлен общий выключатель автоматизации геофайлов, выключенный по умолчанию; ручные правила сохраняются. Стандартные GeoIP/GeoSite доступны в библиотеке с обновлением с GitHub и отдельными расписаниями. Исправлены восстановление DAT при Base64, обрезка категорий клиентом, выбор категорий, удаление используемых файлов и редактирование дополнительных IP. В комплект входят миграция 205 и обновление basic-ftp до 6.2.6. Обновление панели не заменяет отдельно установленную страницу подписки или удалённые ноды.

## English

Cohort: Panel/Page 1.1.7.121, Node 1.1.32, Core 1.1.19 / Xray 26.11.9.

Adds an off-by-default geofile master switch while preserving manual rules. Standard GeoIP/GeoSite sources support GitHub updates and individual schedules. Fixes Base64 DAT recovery, app-side category trimming, selection scope, deletion of referenced sources and secondary-IP editing. Includes migration 205 and basic-ftp 6.2.6. Updating the panel does not replace a separately installed subscription page or remote nodes.

# 1.2.118

- Панель и страница подписки 1.1.7.82: нейтральные индивидуальные имена заголовков CDN с генерацией на закрытом ключе установки. Скопируйте имя из окна настройки и замените его в VK/Яндексе, оставив значение UUID прежним.
- Имя стабильно при обычных обновлениях. Отдельная смена APP_SECRET требует обновить имя в CDN. Сам ключ не передаётся CDN или клиенту. Старое имя и ссылки пользователей продолжают работать.
- Проверяются независимость имён разных установок, два CDN, фильтрация заголовков, JSON, DAT, SHA-256, отзыв токена страницы и совместная работа готовых образов.
- Документация и RU/EN/FA/ZH обновлены. Новых переменных .env и миграций нет. Нода 1.1.19 и Core 1.1.11 прежние.

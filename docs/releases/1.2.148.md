# 1.2.148

- Новый режим отдельного HTTPS-сайта ноды. При установке и переносе задаются режим, порт сайта и порт входа Xray для профиля панели. Порт API задаётся отдельно; при переносе он сохраняется. Проверяются диапазон, совпадения портов и занятый порт сайта.
- Nginx самостоятельно принимает HTTPS на выбранном порту, даже когда профиль Xray не запущен. Режим selfsteal и локальный сокет с PROXY protocol сохраняются. Случайный сайт и собственные правки не заменяются при обновлениях.
- Готовность отдельного сайта проверяется настоящим HTTPS-запросом с проверкой имени домена и установленного сертификата. При смене режима неудачная проверка откатывает настройку.
- Исключение firewall ограничено выбранным TCP-портом сайта. API, остальные порты и ping остаются под ограничением IP главного сервера; SSH сохраняется. Для UFW используется отдельный управляемый профиль без включения изначально выключенного firewall. При изменении режима или удалении ноды исключение снимается.
- При активном UFW доступ к TCP-портам API и выбранного входа Xray разрешается только от IP/CIDR главного сервера. Собственное правило этой установки снимается при удалении ноды; сторонние правила сохраняются.
- Исправлены настройка TLS после переноса, повторное подтверждение домена и HTTP-01 при активном UFW из 1.2.146. UFW восстанавливается после Certbot, включая ошибку и прерывание. DNS-01 не отключает UFW.
- В ошибке сертификата показывается журнал ACME; ошибка Docker безопасно указывает операцию и причину без вывода ключей.
- Удаление ноды включает добавленный после переноса управляемый Nginx, даже если старый список собственных сервисов не был обновлён. Соседние и сторонние proxy сохраняются; собственный таймер продления отключается, файлы сайта и сертификаты не удаляются.

Для каскада с сайтом на 443 и REALITY на 8443 используйте REALITY target `127.0.0.1:443` и `xver: 0`. `acceptProxyProtocol` во входе Xray нужен только при отправке PROXY protocol главным сервером. Установщик сохраняет выбранный порт и показывает инструкцию; существующий профиль в панели он не переписывает. Firewall провайдера настраивается отдельно.

Версии компонентов: Panel/Subscription Page 1.1.7.100, Node 1.1.26, Core 1.1.16. Промежуточный установщик 1.2.147 оставлен неопубликованным; исправления входят в этот выпуск.

# 1.2.129

- Локальная служба отдаёт администратору технические журналы текущего обновления панели и операций страницы подписки. ID задачи и страницы проверяются; произвольные пути, символьные ссылки и специальные файлы отклоняются.
- В скачиваемой копии удаляются секреты окружения, управляющий токен, заголовки авторизации и пароли в URL. Размер скачивания ограничен последним 1 MiB; исходный закрытый журнал сохраняется до следующей операции того же компонента.
- Ошибка запуска фонового worker также получает отдельный подробный журнал.
- Уточнено описание systemd-службы: при загрузке сервера запускается только локальный API; обновление начинается по явному запросу администратора.

Панель и страница подписки 1.1.7.91; Node 1.1.21; Core 1.1.12. Новых переменных `.env` нет.

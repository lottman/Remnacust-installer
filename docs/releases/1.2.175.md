# 1.2.175

Комплект подготовлен для Panel/Page 1.1.7.127, Node 1.1.38 и Core 1.1.22 на официальной основе Xray v26.11.9.

Panel и Node поддерживают обнаружение IPv4 и IPv6. Первый успешный аутентифицированный обмен заполняет обнаруженные адреса, затем автоматическая проверка каждые 30 минут только добавляет новые. Время успешной проверки хранится постоянно и сохраняется после перезапуска панели. Явное повторное сканирование также удаляет исчезнувшие обнаруженные IP. Ручные IP и DNS-имена сохраняются вместе с отключениями и порядком. Полностью выключенный список не включается автоматически. Ошибка связи, неподдерживаемая старая Node или неполный ответ не очищают сохранённые адреса.

Редактор ноды возвращён к компактным строкам с фиолетовой отметкой панельного адреса и переключателем включения вместо удаления. Повторное сканирование доступно после сохранения адресов управления, порта и прокси. Создание ноды проверяет прокси на шаге подключения; финальная проверка возвращает к ошибочному полю. Настроенный SOCKS5 остаётся обязательным для управления, без прямого подключения при отказе прокси.

Уточнены настройки системы геофайлов и JSON-подписки. Исправлена выдача полных стандартных GeoIP/GeoSite и контрольных сумм через страницу подписки. Новый импорт стандартного источника получает интервал 48 часов; автообновление включается отдельно. Существующие интервалы и отключения сохраняются. Ручное обновление файла не ждёт срока автоматического обновления. Закрытие блока стандартных геофайлов сохраняет поля и несохранённое расписание; режим уменьшения движения и мобильная раскладка учитываются.

Установщик сохраняет прежние правила безопасности, firewall, секреты и способ установки готовых образов. Обновление панели не обновляет ноды или приложения клиентов автоматически. Для обнаружения IP нужна Node 1.1.38 или новее; обновляйте выбранные компоненты отдельно. [Порядок работы со списком адресов](../../installer/README.md#обнаруженные-ip-адреса-ноды).

## English

This bundle is prepared for Panel/Page 1.1.7.127, Node 1.1.38 and Core 1.1.22 based on the official Xray v26.11.9 release.

Panel and Node support IPv4 and IPv6 discovery. The first successful authenticated exchange populates discovered addresses; automatic checks every 30 minutes then only append new addresses. The successful scan time persists across panel restarts. An explicit rescan also removes discovered IPs that are no longer present. Manual IPs and DNS names, disabled flags and priority remain. An all-disabled list is never enabled automatically. Connection failures, unsupported older nodes and incomplete responses retain saved addresses.

The node editor returns to compact rows with a purple panel-address badge and an enable switch instead of deletion. Rescanning requires saved control-address, port and proxy changes. Node creation validates the proxy on the connection step and returns to the invalid field during final validation. A configured SOCKS5 proxy remains mandatory for management, without direct fallback on proxy failure.

Geofile-system and JSON-subscription settings are clarified. Full standard GeoIP/GeoSite delivery and checksums through the subscription website are corrected. Importing a standard source for the first time sets an interval of 48 hours; automatic refresh is enabled separately. Existing intervals and disabled settings are preserved. Manual file refresh does not wait for the automatic deadline. Closing the standard-geofiles block retains fields and unsaved schedule edits, with reduced-motion and mobile support.

The installer retains its existing security rules, firewall handling, secrets and prebuilt-image installation workflow. Updating the panel does not automatically update nodes or client applications. IP discovery requires Node 1.1.38 or later; update selected components separately. [Managing the address list](../../installer/README.en.md#discovered-node-ip-addresses).

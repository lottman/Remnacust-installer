# Выпуск Remnacust

Исходники разделены между `Remnacust-panel`, `Remnacust-node`, `Remnacust-core` и `Remnacust-installer` в аккаунте lottman. Репозитории не удаляются при выпуске; новые изменения добавляются обычными коммитами.

1. Выполните проверки изменённых компонентов. Версии панели, ноды и ядра меняйте при изменении самих компонентов; для исправления только установщика общий новый тег не нужен. Архив ядра в ноде должен соответствовать исходникам выбранного ядра.
2. В `component-sources.json` установщика укажите репозиторий, полный хеш коммита и `version` каждого компонента. Обновите собственный `VERSION`, инструкции и тесты установщика, затем создайте новый тег. Например, установщик `v1.1.3` содержит панель `1.1.2`, ноду и ядро `1.1.1`.
3. Из checkout установщика выполните `python3 scripts/package-source-release.py --check v1.1.3`, затем команду без `--check`. Пакетировщик использует выбранный Git-тег и закреплённые коммиты, проверяет собственную версию и версии компонентов, запрещённые файлы. Случайные локальные `.env` не входят в архив.
4. Создайте черновик GitHub Release установщика и добавьте `release/installer.sh`, `release/remnacust-source-v1.1.3.tar.gz` и `release/SHA256SUMS`. Опубликуйте стабильный выпуск с отметкой Latest только после загрузки всех файлов. Workflow `Publish source release` выполняет те же действия при ручном запуске.
5. Проверьте `bash installer.sh --check-release --version 1.1.3`, затем новую установку и обновление на отдельном Linux-стенде. Для следующих исправлений выпуска используйте новый тег; опубликованные теги и файлы сохраняйте.

Пользователь скачивает публичные файлы без токена. Workflow загружает файлы стандартным временным `GITHUB_TOKEN` с правом `contents: write`. Docker-образы собираются на сервере пользователя, поэтому отдельный реестр не нужен.

Для локальной проверки пакетировщика без загрузки других репозиториев задайте `--local-sources /path/to/parent`, где находятся три соседних checkout с нужными коммитами. Полученный архив имеет тот же состав и контрольную сумму.

# 1.2.112

- Исправлена блокировка обычного обновления панели сообщением «Автономность нод не подтверждена». При недоступной проверке, старой панели или неподтверждённой готовности установщик предупреждает и продолжает обновление. Дополнительный флаг не нужен.
- Панель и страница подписки обновлены до 1.1.7.76. Кнопка обновления сразу передаёт задание установщику, без повторной блокировки по состоянию нод.
- Диагностика остаётся ограниченной по времени и не раскрывает технический вывод или секреты. Старый интерактивный CLI не запускается. Флаг --allow-disruption сохранён для совместимости и пропускает диагностику.
- Проверки выпуска, согласованной копии PostgreSQL и Compose сохранены. Квоты, сроки, заморозка и финансовые барьеры не менялись. Новых миграций БД нет; нода 1.1.19 и Core 1.1.11 прежние.

Неподтверждённая автономность не означает готовности к работе без панели: у зависимых нод во время обслуживания возможен перерыв связи. Установщик не отключает ограничения в ядре.

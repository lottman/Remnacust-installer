# 1.2.179

Новые установки используют Valkey 9.1.4 с закреплённым дайджестом образа. Выпуск Valkey устраняет CVE-2026-130822. [Примечания к выпуску Valkey](https://github.com/valkey-io/valkey/releases/tag/9.1.4)

Комплект включает Panel и Subscription Page 1.1.7.140, Node 1.1.39 и Core 1.1.22. Valkey в существующих установках обновляется отдельно от приложения.

## English

New installations use a digest-pinned Valkey 9.1.4 image, which fixes CVE-2026-130822. The bundle includes Panel and Subscription Page 1.1.7.140, Node 1.1.39 and Core 1.1.22. Existing Valkey installations are upgraded separately from the application.

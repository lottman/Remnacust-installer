# 1.2.84

Панель и страница подписки 1.1.7.49. Нода 1.1.18 и Core/WASM 1.1.11 остаются прежними. Новых миграций БД нет.

- Выключенный переключатель «Загружать клиенту» больше не подменяет действие на DIRECT. Встроенные правила используют выбранные DIRECT, REJECT (блокировка), настроенную группу/балансер или прокси. Исправлены GUI и серверная обработка конфигурации из кода для Xray JSON, sing-box, Mihomo, Clash и Stash.
- Выбор действия доступен в обоих режимах. Переключение доставки сохраняет действие. В списке также доступны настроенные прокси YAML-шаблона и префиксы пулов Xray.
- DIRECT остаётся начальным значением новой привязки и значением совместимости для старой встроенной привязки без `target`. Явно пустое, некорректное или отсутствующее в конфигурации действие не заменяется молча: шаблон сохраняется как черновик с предупреждением, подписки используют последнюю рабочую версию.
- Обновлены описания и руководство на RU/EN/FA/ZH. Проверены сохранение REJECT без загрузки, переключение доставки, мобильный экран 320 px, RTL и светлая тема.

Проверки исходников: 650 серверных тестов прошли, четыре платформенных теста пропущены в Windows; 223 теста фронтенда прошли. Проверки типов, локализации, документации и сборки панели завершены успешно. Публикация дополнительно проверяет Linux CI, образы amd64/arm64 и контрольные суммы файлов выпуска.

Обновление панели: `sudo remnacust upgrade-panel --version 1.2.84`. После изменения действия сохраните шаблон и обновите полную JSON/YAML-подписку. Отдельная ссылка VLESS не передаёт маршрутизацию. Ограничения доставки прежние: Xray JSON встраивает правила, бинарный SRS требует удалённой загрузки или импорта исходного JSON для встраивания.

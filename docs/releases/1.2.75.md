# 1.2.75

Не опубликован: проверочный сценарий неверно разбирал пустой ответ HTTP 204. Актуальный выпуск с исправлениями — [1.2.77](https://github.com/lottman/Remnacust-installer/releases/tag/v1.2.77).

Панель и страница подписки 1.1.7.44. Нода 1.1.17, Core/WASM 1.1.11 и официальная база остаются прежними.

- Исправлено удаление несохранённого тестового пула: зависимый балансер, правила и ненужные проверки удаляются одной операцией черновика. Общие источники сохраняются.
- Автовыбор доступен во всех пяти редактируемых форматах: Xray JSON, sing-box, Mihomo, Clash и Stash. Используются нативные группы приложений. Источники по UUID, тегам и regex поддерживают all/random/group; доступ проверяется до отбора. Явно пустой пул не превращается в DIRECT.
- Общая библиотека geofiles: загрузка с ПК или HTTPS, несколько наборов в одном шаблоне, повторное использование готовых файлов. Для DAT выбираются категории и действие; правила компилируются в формат клиента. sing-box JSON/SRS и YAML/text rule providers выдаются по публичным URL панели и страницы подписки в совместимых форматах.
- Импорт ограничен HTTPS/443, проверяет DNS и каждый redirect, блокирует приватные/служебные адреса и закрепляет подключение за проверенным IP. Проверки содержимого, размера, распаковки, глубины и числа записей ограничивают обработку файлов. Управление доступно только администратору; API-токены и роль наблюдателя его не получают.
- Общий нижний блок редактора, отдельные действия форм, мобильные вкладки и RTL. Переводы и руководство обновлены на RU/EN/FA/ZH. DOMPurify обновлён до официальной 3.4.17 с исправлениями безопасности.

Файлы библиотеки общедоступны знающим ссылку: не загружайте секреты. Они хранятся в постоянном каталоге `backups/geofiles`, который требуется копировать отдельно при переносе; резервная копия только БД не содержит бинарные файлы. Удаление защищает текущие шаблоны; историческим версиям после удаления файла может потребоваться повторная привязка. Сырые URI/Base64 не получают вымышленных возможностей импорта правил. Поддержка конкретных правил зависит от версии приложения; проверка каждого физического клиента не заявляется.

Обновление панели: `sudo remnacust upgrade-panel --version 1.2.75`. Нода и ядро не требуют обновления ради этих изменений. После настройки сохраните шаблон и обновите подписку в приложении. Миграций БД в этом выпуске нет.

Форматы и ограничения: [Geofiles](https://github.com/lottman/Remnacust-panel/blob/main/docs/GEOFILES.md), [автовыбор](https://github.com/lottman/Remnacust-panel/blob/main/docs/XRAY-AUTOSELECT.md).

# 1.2.107

Комплект панели и страницы подписки **1.1.7.71**, ноды **1.1.19** и Core **1.1.11**.

- Обнаружение существующих локальных Compose-страниц Remnawave без изменения образа, токена и настроек. Обновление и удаление немигрированной страницы не выполняются автоматически.
- Проверка принадлежности страницы конкретной панели: полный публичный origin либо однозначный внутренний alias в общей сети. Совпадение имени другой панели недостаточно.
- Перезапуск ограничен выбранным сервисом, включая Compose с depends_on.restart.
- Ошибка повторного обнаружения завершает принятое задание, позволяя повторить действие без двухчасового ожидания.
- Добавлены регрессионные проверки и включены в общий запуск установщика.
- В панели исправлены reduced motion, мобильные таблицы и легенда, обновлены четыре локализации и справка.

Новых миграций нет. Нода и Core закреплены за прежними выпущенными версиями. Готовые образы amd64/arm64 публикуются только после проверки сборки и полного комплекта.

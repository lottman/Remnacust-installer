# 1.2.101

Исправление управления страницами подписки. Версии приложений остаются прежними: панель и страница подписки **1.1.7.65**, нода **1.1.19**, Core **1.1.11**. Новая версия относится к установщику.

- Добавлено отдельное удаление страницы: пункт **16** главного меню, пункт **8** в меню управления страницей и команда `uninstall-subscription-page --page-id ID`. Перед удалением показываются проект, домен и состояние; подтверждение по умолчанию — нет.
- Удаляются только контейнеры выбранной страницы и принадлежащего ей отдельного proxy. Общий proxy, панель, база данных и другие сервисы остаются работать. При неоднозначной зависимости операция отклоняется до изменений.
- Настройки, сертификаты, тома и резервные копии сохраняются. Исходный Compose архивируется под `backups/uninstalled-subscription-page-*/`. Удалённая страница исключается из реестра активных страниц и обычного запуска Compose; обновление панели её не включает обратно.
- При ошибке Docker или неподтверждённом удалении восстанавливаются конфигурация и реестр, а прежнее состояние запуска возвращается для затронутых сервисов. Чужие контейнеры не перезапускаются.
- Повторная установка отдельной удалённой страницы сохраняет прежний каталог в `backups/reinstalled-subscription-page-*/configuration`. Рабочая установка остаётся в одном каталоге, сохранённые тома доступны повторно.
- В списке страниц различаются работающий сервис, остановленный контейнер, сохранённые настройки без контейнера и недоступность Docker. Наличие одной панели не означает установку отдельного сайта подписки.

Проверено модульными тестами, интерактивными терминальными сценариями и установкой/обновлением/откатом/удалением на изолированных Docker-проектах. Рабочие пользовательские установки при проверке не удаляются.

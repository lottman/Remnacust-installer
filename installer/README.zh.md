# Remnacust 运维指南

[Русский](README.md) · [English](README.en.md) · [فارسی](README.fa.md) · [简体中文](README.zh.md)

1.2.177 套件包含 Panel/Page 1.1.7.129、Node 1.1.38 和基于 Xray v26.11.9 的 Core 1.1.22。安装器支持 Ubuntu 22.04/24.04/26.04 LTS、Debian 12/13，以及 amd64/arm64 架构。安装使用预构建 Docker 镜像，无需在 VPS 上编译。安装器交互提示目前使用俄语。

## 更新与设置保留

运行 `sudo remnacust --help` 查看命令。`upgrade-panel`、`upgrade-subscription-page` 和 `upgrade-node` 分别更新对应组件；更新面板不会自动更新节点或用户客户端。现有设置、密钥、数据和反向代理配置会保留。完整安装步骤和参数见[英文指南](README.en.md)。

## 公开 GeoIP 和 GeoSite

Page 1.1.7.128 在 `CUSTOM_SUB_PREFIX` 非空时也支持从域名根路径访问公开 geofile 链接，同时保留原有带前缀的链接。不要将私有前缀加入公开 URL。域名访问策略、重定向和 CDN 校验仍然生效。

代理必须将完整的公开 `/geofiles/` 路径转发到同一个 Page，并保留查询参数、GET 和 HEAD。安装器生成的 Caddy 模板转发整个域名及其别名。如果现有 Caddy/Nginx 只转发私有订阅路径，还需要单独将公开 geofile 请求转发到 Page；不要将客户端重定向到私有路径。不要为 Page 请求添加 `/api/sub` 前缀。应用更新会保留现有反向代理，不会自动添加这条规则。

首次导入标准来源时，更新间隔设为 48 小时。文件自动更新需要单独启用，并要求 geofile 系统已开启。再次导入会保留现有间隔和禁用状态。手动更新不等待自动更新时间；更新失败时保留上次有效文件。

## 节点地址

IP 发现需要 Panel 1.1.7.127 或更新版本以及 Node 1.1.38 或更新版本。从 Panel 1.1.7.129 起，每 30 分钟的自动检查和手动扫描均使用节点返回的完整网络地址列表进行协调：添加新地址，并移除已消失且此前被节点确认过的 IP。仅有遥测元数据时不会删除地址。节点从未确认过的手动 IP（包括 NAT 地址）和 DNS 名称会保留；已确认过的 IP 后续可能被移除，即使最初是手动填写的。保留地址的顺序、禁用状态及成功检查时间保持不变。连接失败或响应不完整不会清空列表。扫描前先保存管理地址、端口和代理的修改。

## 安全诊断

geofile 返回 404 时，先检查 Page 版本及代理是否转发公开路径。不要在日志或诊断输出中打印令牌、私有前缀或用户私有地址。不要通过关闭身份验证、证书校验或已配置的 SOCKS5 来规避错误。[发行说明](../docs/releases/1.2.176.md)。

# 1.2.99

Готовый комплект панели и страницы подписки **1.1.7.64**; нода **1.1.19** и Core **1.1.11** используют прежние исходные коммиты.

- При занятом порту страницы подписки установщик проверяет владельца через реестр и точную идентичность Docker Compose. Подтверждённо наша страница обновляется на месте: пересоздаётся только её сервис, сохраняются `.env`, токен, порт и остальные контейнеры.
- Потерянная регистрация восстанавливается только для нашего образа страницы в каталоге текущей установки. Чужой образ, чужой каталог, API панели и неоднозначный владелец не останавливаются. При явном выборе другого проекта или каталога существующая страница не перехватывается.
- Повторная установка уже зарегистрированного проекта открывает управление им. При действительно новом сайте занятый неизвестным сервисом порт можно заменить интерактивно; автоматизация завершится без остановки владельца.
- Ввод домена подтверждается с ответом `y` по умолчанию; отмена возвращает к вводу. Пустые обязательные ответы запрашиваются повторно, EOF прекращает действие. Подтверждения `y/n` сохраняют свои значения по умолчанию.

Обновите установщик перед повтором команды установки. Переустановка страницы сохраняет её существующий домен; смена адреса выполняется отдельной командой управления, чтобы не затронуть внешний reverse proxy случайно.

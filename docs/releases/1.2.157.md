# 1.2.157

Комплект: Panel/Page **1.1.7.111**, Node **1.1.28**, Core/WASM **1.1.17**, Xray **26.11.9**.

- GEO включается отдельно в меню ⋯ каждого шаблона. Состояние видно рядом с меню; новые шаблоны выключены, существующие сохраняют прежнее состояние. Общего переключателя больше нет. JSON на базовом пути остаётся обязательным; ручные правила администратора сохраняются.
- Порог 1–250 000 условий, по умолчанию 20 000 включительно, проверяется отдельно для каждого итогового профиля хоста. Соседние профили не суммируются; только большой профиль переходит на DAT. Защитные бюджеты размера остаются.
- Исправлено лишнее чтение полного каталога шаблонов при запросах подписки: ограниченный кэш с поколениями и объединением одновременных загрузок не заменяет проверку пользовательского доступа, HWID или квот.
- Иконки больше не увеличиваются при нажатии: эффекты работают с деталями SVG и учитывают уменьшение движения. Документация и локализация обновлены на RU/EN/FA/ZH, добавлен пример назначения автовыбора.
- Миграция 202 проверена вместе с остальными миграциями на PostgreSQL 14.24/15.19/16.15/17.11/18.6 под владельцем без superuser. Сверены уже перенесённые исправления безопасности upstream. Обновите отдельно размещённую страницу подписки вместе с панелью; сохраняйте секреты и резервные копии.

## English

Panel/Page **1.1.7.111**, Node **1.1.28**, Core/WASM **1.1.17**, Xray **26.11.9**. Enable geofiles per template through its menu; visible normal/crossed-out icons show the state. Existing state is preserved, new templates default to off. The inline threshold applies per final profile, and only oversized profiles switch to DAT. Independent safety budgets remain. A bounded generation-aware catalogue cache coalesces full-template reads without caching user authorization, HWID or quotas. Icon detail animations replace press scaling and respect reduced motion. Migration 202 and concurrency checks passed on five PostgreSQL majors with restricted owners. Update separately hosted subscription pages along with the panel; keep secrets and backups unchanged. No production servers were updated for this release.

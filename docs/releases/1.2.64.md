# 1.2.64

При обновлении панели отображаются текущий этап из восьми, процент завершённых этапов, прошедшее время и журнал последних 24 событий. Журнал можно скачать в JSON. Оставшееся время оценивается по предыдущему успешному обновлению; без истории показывается число оставшихся этапов. Во время перезапуска API последнее состояние сохраняется, ожидаемые ошибки обслуживания больше не засоряют экран. Полные технические журналы остаются на сервере.

Здоровье недоступной, отключённой или подключающейся ноды равно 0/100. Устаревшие значения не создают видимость работающего ядра. Отсутствующие сведения о ресурсах снижают оценку, а не считаются успешной проверкой.

Установщик проверяет фактический NET_ADMIN внутри контейнера. Уже выданное право сохраняется без повторного вопроса. Если право не подтверждено, интерактивная установка или обновление предлагает выбор. При установке без терминала NET_ADMIN требует явного флага --net-admin.

Исправлен сбор сессий: наблюдение IP включается на всех уровнях политики независимо от NET_ADMIN. Персональные идентификаторы устройств и хостов связываются с владельцем; повторные IP объединяются с сохранением последнего времени наблюдения. Ошибки Xray больше не выдаются за успешный пустой список. Частичные результаты сопровождаются предупреждением о неответивших нодах и неизвестных идентификаторах. Запись сохраняет полученные наблюдения и отмечает неполные опросы.

Для исправления сбора обновите и панель, и ноду, затем дождитесь применения конфигурации. Это периодический опрос активных авторизованных сессий: короткие подключения между опросами могут быть пропущены. Документация и переводы синхронизированы.

Компоненты: панель 1.1.7.35, нода 1.1.12, ядро 1.1.7. Ядро сохраняет код предыдущего выпуска. Новых миграций базы нет.

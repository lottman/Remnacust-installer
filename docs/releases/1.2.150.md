# 1.2.150

Согласованный комплект: Panel/Subscription Page **1.1.7.104**, Node **1.1.27**, Core/WASM **1.1.17** на основе **Xray v26.11.9**.

- Прежний основной домен можно удалить с явным подтверждением перевода его пользователей на текущий домен по умолчанию. Привязки и удаление изменяются одной транзакцией; ключи, заморозка, сроки и лимиты сохраняются.
- Режим «Закрыт» запрещает доступ к основному домену вместе с его CDN либо к отдельному CDN. Подписанный заголовок не обходит запрет. Последний доступный основной домен нельзя закрыть или удалить.
- Карточка пользователя, её QR и API ссылок скрывают закрытые адреса, а также основные адреса с перенаправлением или доступом только через CDN. Пустой список не подменяется старой ссылкой.
- Панель применяет 198-ю миграцию. Сохраняются исправления DAT/JSON, совместимость штатных нод и обновление Xray v26.11.9. Для получения геофайлов через отдельную страницу подписки обновите также эту страницу и проверьте передачу /geofiles/ через прокси/CDN.

Комплект 1.2.149 не публиковался: его сборка была остановлена до выпуска. Существующие теги и файлы не перезаписываются. Установщик не перезагружает сервер; обновление Xray не заменяет исправленное ядро Linux.

## English

Pinned bundle: Panel/Page **1.1.7.104**, Node **1.1.27**, Core/WASM **1.1.17**, based on **Xray v26.11.9**. Adds atomic user reassignment when retiring a former primary, explicit closure of primary/CDN families or individual CDNs, last-primary protection and consistent available links/QR codes. Includes migration 198 and retains the DAT/JSON fixes. Update separately hosted subscription pages and ensure /geofiles/ is forwarded through their reverse proxy and CDN. Bundle 1.2.149 was canceled before publication; existing tags and assets are preserved. No automatic reboot; Xray's MPTCP default is not a Linux kernel patch.

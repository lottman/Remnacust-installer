# 1.2.119

- Панель и страница подписки 1.1.7.83: исправлены DIRECT/REJECT и балансировка по GeoIP для доменных адресов; добавлены несколько публичных ссылок пользователя и отдельные права API на обычные/CDN-ссылки. На основной домен допускается до трёх CDN, включая защиту от одновременного добавления сверх лимита.
- Образ Node 1.1.20 содержит Core 1.1.12 на опубликованном стабильном Xray v26.10.31. MPTCP выключен по умолчанию; исходящий формат XDRIVE сохранён для старых узлов. Панель, валидатор и исходный архив ноды используют согласованное ядро.
- Новых переменных .env и миграций относительно комплекта 1.2.118 нет. Основной домен и настройки CDN сохраняются. Для новых правил обновите подписку в приложении; ядро удалённых нод обновляется отдельно через штатное управление нодой/Core.

# 1.2.177

2026-11-16

Комплект: Panel/Page 1.1.7.129, Node 1.1.38 и Core 1.1.22 на основе Xray v26.11.9.

Автоматическая проверка IP каждые 30 минут и ручное сканирование используют полный ответ ноды для сверки списка. Новые адреса добавляются, ранее подтверждённые нодой исчезнувшие IP удаляются. Ручные IP, никогда не подтверждённые нодой, включая NAT, и DNS-имена сохраняются. Ранее подтверждённый IP может быть удалён, даже если первоначально его ввели вручную. Отключения и порядок оставшихся адресов сохраняются; ошибка, неполный ответ или одни метаданные телеметрии не дают основания удалять адреса.

HOST проверяет согласованность пары профиль/inbound в форме, карточках, таблице и при клонировании. Backend отклоняет клонирование удалённой или чужой привязки до записей; корректная копия по-прежнему создаётся выключенной. Недоступность ноды сама по себе не делает привязку недействительной.

API возвращает корректный ответ, когда системная информация ноды отсутствует. Неизвестная телеметрия остаётся неизвестной. Прокрутка оглавления документации и бокового меню сохраняет позицию основной статьи при достижении границ; клавиатура, touch и RTL поддерживаются.

Версии Node и Core не изменились. Компоненты обновляются отдельно; обновление панели не обновляет ноды или клиентские приложения. [Руководство оператора](../../installer/README.md).

## English

Bundle: Panel/Page 1.1.7.129, Node 1.1.38 and Core 1.1.22 based on Xray v26.11.9.

Automatic IP checks every 30 minutes and manual rescans reconcile the list using a complete node response. New addresses are added; previously confirmed IPs that disappeared are removed. Manual IPs never confirmed by the node, including NAT addresses, and DNS names remain. A previously confirmed IP can be removed even if it was originally entered manually. Disabled flags and priority of retained addresses remain. Errors, incomplete responses and telemetry metadata alone do not authorize address removal.

HOST uses consistent profile/inbound validation in forms, cards, tables and cloning. The backend rejects removed or mismatched bindings before clone writes; valid clones remain disabled. Node availability alone does not determine binding validity.

The API returns a correct response when node system information is missing. Unknown telemetry remains unknown. Documentation contents and sidebar scrolling retain the article position at pane boundaries, including keyboard, touch and RTL navigation.

Node and Core versions are unchanged. Update components separately; updating the panel does not update nodes or client applications. [Operator guide](../../installer/README.en.md).

## فارسی

بستهٔ 1.2.177 شامل Panel/Page 1.1.7.129، Node 1.1.38 و Core 1.1.22 بر پایهٔ Xray v26.11.9 است.

بررسی خودکار IP هر ۳۰ دقیقه و اسکن دستی، فهرست را با پاسخ کامل نود تطبیق می‌دهند. نشانی جدید اضافه و IP قبلاً تأییدشدهٔ ناپدیدشده حذف می‌شود. IP دستی که نود هرگز تأیید نکرده، از جمله NAT، و نام DNS حفظ می‌شود. IP قبلاً تأییدشده ممکن است حذف شود، حتی اگر ابتدا دستی وارد شده باشد. ترتیب و حالت غیرفعال نشانی‌های باقی‌مانده حفظ می‌شوند. خطا، پاسخ ناقص یا فرادادهٔ تله‌متری به‌تنهایی مجوز حذف نیست.

اعتبارسنجی جفت پروفایل/inbound در فرم، کارت، جدول و کپی HOST یکسان است. Backend پیش از نوشتن، کپی اتصال حذف‌شده یا متعلق به پروفایل دیگر را رد می‌کند؛ کپی معتبر همچنان غیرفعال ساخته می‌شود. قطع‌بودن نود به‌تنهایی اتصال را نامعتبر نمی‌کند.

وقتی اطلاعات سیستمی نود موجود نیست، API پاسخ درست برمی‌گرداند. تله‌متری نامعلوم، نامعلوم باقی می‌ماند. پیمایش فهرست مستندات و منوی کناری در مرزها موقعیت مقاله را حفظ می‌کند؛ صفحه‌کلید، لمس و RTL پشتیبانی می‌شوند.

نسخه‌های Node و Core تغییر نکرده‌اند. اجزا جداگانه به‌روزرسانی می‌شوند؛ به‌روزرسانی پنل نودها یا برنامهٔ کاربران را به‌روزرسانی نمی‌کند. [راهنمای اپراتور](../../installer/README.fa.md).

## 简体中文

1.2.177 套件包含 Panel/Page 1.1.7.129、Node 1.1.38，以及基于 Xray v26.11.9 的 Core 1.1.22。

每 30 分钟的自动 IP 检查和手动扫描均使用节点的完整响应协调列表。添加新地址，并移除已消失且此前被节点确认过的 IP。节点从未确认过的手动 IP（包括 NAT 地址）和 DNS 名称会保留。已确认过的 IP 后续可能被移除，即使最初是手动填写的。保留地址的顺序和禁用状态不变。错误、不完整响应或仅有遥测元数据时，不会据此删除地址。

HOST 表单、卡片、表格和克隆使用一致的配置/inbound 绑定校验。后端在写入前拒绝克隆已移除或不匹配的绑定；有效副本仍以禁用状态创建。节点不可达本身不会使绑定失效。

节点系统信息缺失时，API 仍会返回正确响应。未知遥测保持未知。文档目录和侧栏滚动到边界时保留正文位置，并支持键盘、触摸及 RTL 导航。

Node 和 Core 版本未变。组件分别更新；更新面板不会自动更新节点或用户客户端。[运维指南](../../installer/README.zh.md)。

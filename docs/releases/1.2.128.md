# 1.2.128

- Подробный журнал создаётся до проверки установки и обновления системных пакетов. Он содержит UTC-время, этапы, длительность, вывод, коды завершения и место ошибки без трассировки аргументов или окружения.
- Сохраняется один CLI-журнал на компонент: `installer-panel.log`, `installer-node.log`, `installer-subscription-page.log`. Следующее действие того же компонента заменяет его; проверки состояния используют отдельный `installer-diagnostics.log`. Одновременный запуск не стирает активный журнал.
- При ошибке, Ctrl+C, HUP или TERM сохраняется журнал и показывается команда просмотра. При SIGKILL или отключении питания обработчик не выполняется; путь уже напечатан в начале, записанные данные остаются на диске.
- Вывод интерактивного APT записывается через отдельный терминал без эха ввода и без журнала ввода. Вопросы настройки пакетов остаются интерактивными; `-y` подтверждает обычное продолжение APT.
- Обновление из панели сохраняет `panel-update-<ID>.log`; операции страниц — `page-<ID страницы>-<ID задачи>.log`. Предыдущий журнал заменяется только для того же компонента/страницы. Причины исключений сохраняются только в закрытом журнале.
- Права каталога журналов `0700`, файлов `0600`; символические ссылки не используются для открытия журнала. В публичную подписку журналы не передаются.

Комплект панели/страницы 1.1.7.90, Node 1.1.21 и Core 1.1.12. Новых переменных `.env` нет. Перенос сохраняет неизвестные данные и останавливается при несовместимой истории БД; универсальная совместимость с любым сторонним изменением не заявляется.

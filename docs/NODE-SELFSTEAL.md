# Сайт selfsteal на ноде

[Русский](NODE-SELFSTEAL.md) · [English](NODE-SELFSTEAL.en.md)

При установке ноды с собственным доменом установщик автоматически выбирает случайный сайт из локального каталога. В каталоге не менее 20 вариантов на разные темы: от обуви и кофе до Minecraft-хостинга. Все страницы, стили, скрипты и графика поставляются вместе с установщиком; внешние CDN для их работы не нужны.

Выбор выполняется один раз. Перезапуск, обновление ноды и продление сертификата не выбирают новый вариант. Если вы изменили содержимое сайта, установщик сохраняет ваши файлы.

## Установка

Запустите `install-node` с параметром `--node-domain` либо укажите домен в интерактивной установке. Подтвердите домен и выберите способ получения сертификата. Отдельного вопроса о теме сайта нет: вариант выбирается автоматически.

Для selfsteal домен должен вести на IP ноды и работать в DNS-only, без CDN с завершением TLS. Профиль Xray принимает HTTPS на внешнем порту и направляет обычные обращения на локальный TLS-сайт Nginx. В штатной схеме установщика Nginx использует сокет `/var/lib/remnacust/run/nginx.sock` и PROXY protocol; параметры `target` и `xver` профиля должны соответствовать этой схеме. Сами файлы сайта не создают и не изменяют inbound в панели. Пока подходящий профиль Xray не запущен, наличие файлов не означает, что публичный HTTPS уже доступен.

## Файлы и правки

При стандартном размещении файлы находятся в `/opt/remnacust/node/www/`. Изменяйте HTML, CSS, JavaScript и графику в этом каталоге. Сайт статический: каталог товаров, подборки, фильтры и калькуляторы работают в браузере. Для реальных заказов, оплаты или создания игровых серверов нужно отдельно подключить собственную службу и контакты; таких действий сайт сам не выполняет.

Не размещайте в `www` `.env`, ключи, дампы или резервные копии. Каталог доступен посетителям. Настройки выбранного варианта хранятся отдельно от публичных файлов.

## Другой случайный сайт

В актуальном установщике откройте «Управление → Нода → Выбрать другой случайный сайт» либо выполните:

```bash
sudo remnacust configure-node-site
```

После подтверждения текущие файлы сохранятся в `/opt/remnacust/backups/node-sites/`, затем будет выбран другой вариант. Работающий Nginx пересоздаётся для подключения нового каталога; остановленный сайт не запускается. Процесс Xray и его профиль это действие не изменяет. Если Nginx не удастся запустить, установщик попробует восстановить прежний сайт и покажет результат в журнале.

Команда доступна в версии установщика с каталогом сайтов. Если установленный CLI её ещё не знает, сначала скачайте актуальный `installer.sh` из Latest и запустите команду через него.

## Исходники вариантов

Все варианты находятся в `sites/` этого репозитория. `scripts/build-node-sites.py` собирает проверенный каталог для установщика. При добавлении собственного варианта нужны как минимум главная страница, страница о сайте и страница 404; все локальные ссылки и ресурсы должны существовать. Сборка и проверки каталога выполняются перед публикацией.

# 1.2.116

- Панель и страница подписки 1.1.7.80: один раз добавьте заголовок запроса `X-Remnacust-CDN` с UUID CDN-домена в VK или Яндексе. Обычные ссылки подписок сохраняются без замены, геофайлы и ссылки устройств остаются на CDN даже при подмене Host.
- Окно «Настроить CDN» показывает готовые имя/значение, источник, Host и SNI с копированием. Преобразование ссылок остаётся свёрнутым запасным способом.
- Совместный тест готовых образов проверяет обычный URL с заголовком, отказ для неизвестного UUID и конфликт заголовка с путём. Проверки статуса, заморозки, срока, ключа и HWID сохранены; UUID не является авторизацией.
- Документация и RU/EN/FA/ZH обновлены. Новых миграций и переменных .env нет. Нода 1.1.19 и Core 1.1.11 прежние.

# 1.2.111

- Панель и страница подписки 1.1.7.75; Node 1.1.19 и Core 1.1.11 сохранены.
- Перед остановкой панели установщик требует подтверждения автономности обслуживающих нод. Ошибка, legacy-политика, recovery или неподтверждённая ревизия оставляют приложения работающими.
- Старая панель без новой команды проверяется из нового образа во временном контейнере без writable root, дополнительных capabilities, Docker socket и host mounts. Контейнер использует сеть текущей панели; секреты передаются через приватный временный файл и не выводятся.
- Явный `--allow-disruption` допускает осознанное обслуживание с возможным перерывом, только для одной операции upgrade-panel. `--yes` не включает этот режим.

Готовые образы и архивы для amd64/arm64. Предыдущие выпуски и их файлы не заменяются. Новых миграций БД в панели 1.1.7.75 нет; при переходе с более старых версий сохраняются их штатные миграции и резервное копирование.

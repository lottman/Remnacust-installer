# 1.2.173

В Panel добавлены примечания до окончания активной подписки с выбором сквадов и маркером {HOSTS}, который сохраняет обычные права доступа. Перед публикацией release-образ ноды проходит mTLS/JWT, запуск Core, восстановление пользователей и повторный запуск контейнера на каждой архитектуре.

Миграция ревизии кэша защищает сохранение примечаний и назначений шаблонов внешних сквадов от поздних записей старых запросов. Ограничен общий размер заголовков подписки с сохранением хотя бы одного предупреждения и заданного блока хостов.

Новый комплект включает Node 1.1.36 и Panel/Page 1.1.7.125 с исправлением ложного online: учитываются свежесть состояния Core, явный отказ Core, ошибки SOCKS-прокси и приоритет статусов интерфейса. Core/WASM остаётся 1.1.21; теги прежних выпусков не заменяются.

Объединённый исходный архив сохраняет upstream-security/ с manifest и module locks для Node packager и default WASM. Контракт помощников и самодостаточный Install.sh пересобраны для 1.2.173.

Согласованный комплект: Panel/Page 1.1.7.125, Node 1.1.36, Core/WASM 1.1.21 на официальном Xray v26.11.9. Node.js обновлён до security release 26.13.1 LTS. Обновлены совместимые зависимости, образы и закреплённые инструменты сборки.

Новые установки используют PostgreSQL 18.7, Valkey 9.1.3 и Caddy 2.11.9. Обычное обновление приложений сохраняет существующие dependency-контейнеры, тома и major PostgreSQL. Переход major БД не выполняется скрытно. Сохранены проверки миграции с Remnawave, откат, приватное состояние ноды и IPv6-настройки.

Core исправляет Xera/XHTTP, ECH, публикацию TLS-сертификатов и крупные буферы Vision. Форматы транспортов сохраняются; новые ограничения ресурсов не являются гарантией обхода блокировок. Для клиентских исправлений требуется соответствующее ядро клиента. Обновление панели не заменяет удалённые ноды и отдельно закреплённые managed-ядра.

## English

Panel adds pre-expiry remarks for active subscriptions, with squad targeting and a {HOSTS} marker that preserves normal access controls. Before publication, each architecture of the release Node image passes mTLS/JWT, Core startup, user-state recovery and container restart checks.

A cache-revision migration protects external-squad remarks and template assignments from late writes by older requests. Bounds aggregate subscription headers while retaining at least one notice and the configured hosts block.

The new bundle includes Node 1.1.36 and Panel/Page 1.1.7.125 with false-online fixes covering Core-state freshness, explicit Core failure, SOCKS proxy errors and UI status priority. Core/WASM remains 1.1.21; earlier release tags are not replaced.

The combined source archive retains upstream-security/ with its manifest and module locks for the Node packager and default WASM. Rebuilds the helper contract and standalone Install.sh for 1.2.173.

Matching bundle: Panel/Page 1.1.7.125, Node 1.1.36 and Core/WASM 1.1.21 on official Xray v26.11.9. Updates Node.js to security release 26.13.1 LTS, compatible dependencies, images and pinned build tools.

New installations use PostgreSQL 18.7, Valkey 9.1.3 and Caddy 2.11.9. Ordinary application upgrades preserve existing dependency containers, volumes and the PostgreSQL major. Database major upgrades are not performed silently. Preserves Remnawave migration checks, rollback, private node state and IPv6 configuration.

Core fixes Xera/XHTTP, ECH, TLS certificate publication and oversized Vision buffers. Transport formats remain compatible; resource limits do not guarantee censorship evasion. Client-side fixes require a matching client core. Updating Panel does not replace remote nodes or separately pinned managed cores.

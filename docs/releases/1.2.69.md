# 1.2.69

Исправлен пустой список «Проверенная сборка» в задачах нод. Панель содержит проверенный каталог ядра 1.1.9 для amd64 и arm64 с реальными публичными файлами и контрольными суммами. Версия выбирается сразу; недоступная прежняя запись заменяется актуальной. Загрузка, пустой список и ошибка показываются явно, доступна повторная загрузка.

Нода теперь может скачать эти бинарники: по умолчанию разрешён точный адрес файла нашего репозитория, а перенаправление GitHub проверяется перед скачиванием. Проверки контрольной суммы, архитектуры, конфигурации, квот и откат сохранены. Настроенные вручную каталоги и списки разрешённых хостов сохраняют приоритет; намеренно пустой каталог не заменяется встроенным.

Компоненты: панель и страница подписки 1.1.7.39, нода 1.1.15, ядро и браузерный валидатор 1.1.9. Для полного исправления обновите панель и ноды. Новых миграций и изменений клиентских протоколов нет.

Бинарники ядра собраны и проверены нативно на обеих архитектурах; опубликованные файлы скачаны анонимно и сверены с SHA-256 и ELF-заголовками. Интерфейс проверен на мобильном экране, включая пустой каталог и ошибку загрузки. Пакетировщик больше не допускает выпуск панели с каталогом, отставшим от закреплённого ядра. Установка ядра на рабочие ноды пользователя этим выпуском автоматически не выполняется.

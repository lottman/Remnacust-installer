# 1.2.102

Комплект панели и страницы подписки **1.1.7.66**, ноды **1.1.19** и Core **1.1.11**. Панель добавляет бессрочные API-токены, минимальный набор прав для пользовательских ботов и согласованные права сайта подписки.

- При установке панели мастер объясняет выбор страницы подписки: установить новую на отдельном домене, оставить выдачу через панель или использовать заданный существующий сайт без нового контейнера.
- `--yes` использует безопасные значения необязательных настроек без скрытых вопросов. Для нового сайта явно задайте `--subscription-page --subscription-urls ...`; обязательный домен сайта проверяется без бесконечного повтора. Интерактивная установка сохраняет вопросы и повторный ввод пустых обязательных значений.
- Занятый порт страницы можно заменить. Порты самой панели, 80 и 443 не принимаются; чужие процессы не завершаются.
- При повторной установке отдельной страницы на той же панели её действующий сохранённый токен проверяется внутри панели и переиспользуется с прежними UUID и сроком. Отозванный UUID не восстанавливается, чужой токен и расширенные права не принимаются за служебный токен сайта.
- Из служебного токена удаляется только известное устаревшее лишнее право `subscription:get`; остаются четыре необходимых права. GUI использует тот же набор. Для старых username-ссылок Marzban отдельно требуется `users:by-username` при включении этой совместимости.

Проверены терминальные сценарии выбора сайта, отказа, автоматической установки, отсутствующего домена и конфликта портов, а также сохранение секретов, повторное использование токена и изолированный Docker-цикл установки, обновления, отката, удаления и повторной установки.

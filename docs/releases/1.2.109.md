# 1.2.109

Комплект панели и страницы подписки **1.1.7.73**, ноды **1.1.19**, Core **1.1.11**.

- Исправлен выбор DAT для больших конфигураций Happ/INCY: учитываются разворачивание строковых списков Xray и форматирование приложением. Размер оценивается отдельно по профилям, а не суммой хостов.
- Геофайлы и контрольные суммы выдаются через HTTPS-домен текущего запроса подписки, включая CDN. Обновите и панель, и страницу подписки; прокси должен сохранять исходный Host. Передаваемый страницей адрес принимается только с действующим API-токеном с правами страницы.
- В редакторе геофайлов оставлено одно объяснение доставки; предупреждение о JSON появляется только при выключенной настройке. Документация и четыре локализации обновлены.

Новых миграций БД нет. Нода и Core закреплены за прежними выпущенными версиями. Перед обновлением сохраните резервную копию; после обновления обновите подписку в приложении. Проверка ядрами выполнялась без запуска VPN; физический iPhone в проверке не использовался.

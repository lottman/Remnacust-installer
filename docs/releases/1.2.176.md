# 1.2.176

Комплект: Panel/Page 1.1.7.128, Node 1.1.38 и Core 1.1.22 на основе официального Xray v26.11.9.

Page обслуживает публичные geofile-ссылки от корня домена при непустом `CUSTOM_SUB_PREFIX`. Старые ссылки с префиксом сохраняются; доступ домена, перенаправления и проверки CDN продолжают действовать. Исправление не раскрывает приватный префикс в публичных URL. Поддерживаются обычные файлы, bundles, контрольные суммы, GET и HEAD.

Существующий reverse proxy должен передавать публичный `/geofiles/` той же странице подписки с query-параметрами. Шаблон Caddy установщика проксирует домен и aliases целиком. Если внешний Caddy/Nginx обслуживает только приватный путь подписки, для geofile-запросов нужно отдельное правило; обновление приложения не меняет стороннюю конфигурацию proxy. Не перенаправляйте клиента на приватный путь и не добавляйте `/api/sub` перед запросами к Page.

В комплект входят обнаружение IPv4/IPv6 ноды и сохранение времени успешной проверки. Автоматическая проверка каждые 30 минут только добавляет адреса; ручное повторное сканирование также удаляет исчезнувшие обнаруженные IP. Ручные IP/DNS, отключения и порядок сохраняются. Сбой связи или неполный ответ не очищает список. Новый стандартный geofile получает интервал 48 часов; автообновление включается отдельно, а ручное обновление не ждёт расписания.

Недоступный peer больше не обязан блокировать старт независимых базовых подключений. Зависящие от неподтверждённой политики подключения остаются заблокированы с предупреждением до полного подтверждения и ACK. Успешная проверка API сама по себе не означает, что Core запущен. Проверки лимитов, SOCKS5 и аутентификации сохраняются.

Компоненты обновляются отдельно: обновление панели не обновляет ноды и клиентские приложения. [Руководство оператора](../../installer/README.md).

Устранено краткое переключение языка интерфейса при загрузке. Повторное сканирование адресов в редакторе ноды представлено кнопкой с иконкой. Переключатель последнего включённого адреса управления заблокирован в редакторе, чтобы случайно не выключить все адреса.

## English

Bundle: Panel/Page 1.1.7.128, Node 1.1.38 and Core 1.1.22 based on official Xray v26.11.9.

Page serves public geofile links from the domain root with a nonempty `CUSTOM_SUB_PREFIX`. Existing prefixed links, domain access rules, redirects and CDN checks remain supported. The private prefix stays out of public URLs. Regular files, bundles, checksums, GET and HEAD are supported.

Existing reverse proxies must forward public `/geofiles/` requests to the same subscription Page, including query parameters. The installer's Caddy template proxies the entire domain and its aliases. A Caddy/Nginx configuration that forwards only the private subscription path needs a separate geofile rule; application upgrades do not rewrite external proxy configuration. Do not redirect clients to the private path or prepend `/api/sub` to Page requests.

The bundle includes IPv4/IPv6 discovery and a persistent successful-scan time. Automatic checks every 30 minutes only append addresses; manual rescans also remove discovered IPs that disappeared. Manual IP/DNS entries, disabled flags and priority remain. Connection failures and incomplete responses do not clear the list. New standard geofiles use a 48-hour interval; automatic refresh is enabled separately and manual refresh does not wait for the schedule.

An unavailable peer need not block independent basic connections from starting. Connections dependent on unverified policy stay blocked with a warning until full proof and ACK. API success alone does not mean Core is running. Limits, SOCKS5 and authentication checks remain enforced.

Components are updated separately; a panel update does not update nodes or client applications. [Operator guide](../../installer/README.en.md).

The interface no longer briefly switches language during loading. The node editor uses an icon button for address rescanning. Its last enabled management address has a disabled switch to prevent accidentally turning every address off.

## فارسی

بستهٔ 1.2.176 شامل Panel/Page 1.1.7.128، Node 1.1.38 و Core 1.1.22 بر پایهٔ Xray v26.11.9 است.

Page با `CUSTOM_SUB_PREFIX` غیرخالی نیز پیوندهای عمومی geofile را از ریشهٔ دامنه می‌پذیرد؛ پیوندهای قبلی، سیاست دامنه و بررسی‌های CDN حفظ می‌شوند. پیشوند خصوصی در URL عمومی قرار نمی‌گیرد. فایل معمولی، bundle، checksum، GET و HEAD پشتیبانی می‌شوند.

پروکسی موجود باید مسیر عمومی `/geofiles/` و query را به همان Page بفرستد. قالب Caddy کل دامنه و نام‌های مستعار را عبور می‌دهد. پروکسی محدود به مسیر خصوصی، به قاعدهٔ جداگانه برای geofile نیاز دارد؛ به‌روزرسانی برنامه آن را خودکار تغییر نمی‌دهد. کاربر را به مسیر خصوصی redirect نکنید و `/api/sub` را به درخواست Page اضافه نکنید.

کشف IPv4/IPv6 و زمان بررسی موفق حفظ می‌شوند. بررسی خودکار هر ۳۰ دقیقه فقط نشانی اضافه می‌کند؛ اسکن دستی IPهای کشف‌شدهٔ ناپدیدشده را نیز حذف می‌کند. نشانی دستی، ترتیب و حالت غیرفعال حفظ می‌شوند. منبع استاندارد جدید بازهٔ ۴۸ ساعت دارد؛ به‌روزرسانی خودکار جداگانه فعال می‌شود.

اتصال‌های پایهٔ مستقل می‌توانند بدون انتظار برای peer قطع‌شده راه‌اندازی شوند؛ اتصال وابسته به سیاست تأییدنشده تا اثبات کامل و ACK با هشدار مسدود می‌ماند. موفقیت API به‌تنهایی به معنی اجرای Core نیست. محدودیت‌ها و بررسی‌های احراز هویت و SOCKS5 حفظ می‌شوند. اجزا جداگانه به‌روزرسانی می‌شوند. [راهنمای اپراتور](../../installer/README.fa.md).

تغییر کوتاه زبان رابط هنگام بارگذاری برطرف شده است. اسکن مجدد نشانی در ویرایشگر نود با دکمهٔ آیکون انجام می‌شود. کلید آخرین نشانی مدیریت فعال در ویرایشگر قفل است تا همهٔ نشانی‌ها به‌اشتباه غیرفعال نشوند.

## 简体中文

1.2.176 套件包含 Panel/Page 1.1.7.128、Node 1.1.38，以及基于 Xray v26.11.9 的 Core 1.1.22。

Page 在 `CUSTOM_SUB_PREFIX` 非空时也支持从域名根路径访问公开 geofile。原有带前缀链接、域名策略和 CDN 校验保持有效，公开 URL 不会包含私有前缀。支持普通文件、bundle、校验和、GET 和 HEAD。

现有代理必须将公开 `/geofiles/` 路径及查询参数转发到同一个 Page。安装器的 Caddy 模板转发整个域名及其别名。只转发私有路径的代理需要单独添加 geofile 规则；应用更新不会自动修改外部代理配置。不要将客户端重定向到私有路径，也不要为 Page 请求添加 `/api/sub` 前缀。

套件保留 IPv4/IPv6 发现及成功检查时间。每 30 分钟的自动检查只追加地址；手动重新扫描还会移除已消失的发现 IP。手动地址、顺序和禁用状态保持不变。新标准来源使用 48 小时间隔，自动更新需单独启用。

独立的基础连接无需一直等待不可达 peer；依赖未确认策略的连接继续阻止访问并显示警告，直到完整验证及 ACK。API 成功不代表 Core 已运行。配额、身份验证和 SOCKS5 检查仍然生效。组件分别更新。[运维指南](../../installer/README.zh.md)。

修复了界面加载时语言短暂切换的问题。节点编辑器使用图标按钮重新扫描地址。最后一个已启用的管理地址开关会被锁定，防止意外禁用所有地址。

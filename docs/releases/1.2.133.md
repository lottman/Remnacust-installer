# 1.2.133

Согласованный комплект панели и страницы подписки 1.1.7.94, Node 1.1.22, Core 1.1.13.

- Массовые проверки доступа к хостам переведены на SQL-наборы. Одновременно синхронизируются не более трёх нод на процесс; повторные запросы одной ноды объединяются, а занятая advisory-блокировка повторяется вне SQL-транзакции.
- Страницы с выключенным показом ключей не создают ненужные ссылки. Прежний API старых страниц сохранён; обновлённая страница ожидает сведения до 30 секунд.
- Базовая конфигурация совместима со штатными Remnawave-нодами. Расширенные квоты, скорость, правила назначения и специальный доступ при неактивной подписке требуют совместимых Node/Core и не отключаются.
- Исправлено ожидание PostgreSQL в проверке восстановления: проверяется рабочий TCP-сервер, а не временный Unix-сокет инициализации контейнера.

Новых миграций и переменных `.env` нет. Обновление панели не заменяет ядро удалённых нод; для новых возможностей обновите ноду штатной командой. Подробности — в выпуске панели 1.1.7.94 и документации RU/EN/FA/中文.

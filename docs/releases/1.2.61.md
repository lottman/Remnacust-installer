# 1.2.61

В Sessions Explorer появилась вкладка записи: задайте длительность и интервал, затем скачайте JSON с найденными пользователями, актуальными ссылками подписок, IP, нодами и временем наблюдений. Запись продолжается при закрытой вкладке; пропущенные опросы и лимит объёма видны в интерфейсе. Поиск текущих сессий поддерживает имя пользователя, ID, IP и ноду.

При установке ноды установщик спрашивает о NET_ADMIN. При обновлении уже включённое право сохраняется без вопроса; если оно отсутствует, его можно добавить. Остальные права, секреты, тома и настройки Compose сохраняются. Диагностические записи хранятся 3 дня после окончания и не увеличивают штатные резервные копии.

Также исправлены история профилей, состояние редактора при изменении ширины экрана и восстановление ядра после перезапуска ноды без панели. Внутренние сокеты управления теперь находятся в приватном каталоге; исправлены восстановление API в Lua-режиме и работа XHTTP с конфигурацией соединений.

Компоненты: панель 1.1.7.33, нода 1.1.11, ядро 1.1.7. Основа Xray остаётся официальным тегом v26.10.10 (prerelease).

Запись — периодические снимки активных подключений, поэтому короткая сессия между опросами может быть пропущена. Одна запись активна одновременно; до 20 записей и 20 000 сочетаний пользователь/нода/IP на запись. Файл подписок храните приватно. Обновление не обещает проверку всех сторонних приложений, внешних IdP и инфраструктуры провайдера.

Подготовка тестовых каталогов исправлена для GitHub Runner без root; тег 1.2.60 не публиковался как выпуск.

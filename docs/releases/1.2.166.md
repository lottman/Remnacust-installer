# 1.2.166

- Комплект: Panel/Page 1.1.7.118, Node 1.1.31, Core 1.1.19 / Xray v26.11.9.
- Исправлена передача выбранного времени автоматической разморозки во всех формах пользователей; сохранены локальные часы и минуты, проверки прав и неизменяемость сохранённой даты.
- Панель исправляет открытие пользователя после настроек доменов и локальные схемы редакторов Mihomo и sing-box.
- Новая установка панели использует PostgreSQL 18.6. Обновление приложения сохраняет существующий образ БД, тома и настройки. Для обновления БД сначала создайте резервную копию и оставайтесь в пределах её основной версии.
- Образы панели, ноды и страницы подписки выпускаются согласованным комплектом для amd64 и arm64. Удалённые ноды и отдельно установленная страница не обновляются вместе с панелью автоматически.

## English

Pins Panel/Page 1.1.7.118, Node 1.1.31 and Core 1.1.19 / Xray v26.11.9. Fixes selected automatic activation times in all user forms while preserving authorization and saved-deadline immutability. Fresh panel installations use PostgreSQL 18.6; application upgrades retain the current database image, volumes and settings. Back up and update the database separately within its existing major version. Images form a matching amd64/arm64 cohort. Remote nodes and separate subscription websites require separate updates.

Выпуск включает панель 1.1.7.32, ноду 1.1.10 и ядро 1.1.6.

### Порты и профили

- Независимые конфигурации портов с просмотром изменений и историей. Один исходный inbound можно назначить нескольким портам без дублирования прав пользователя.
- Поддерживаемые изменения профиля применяются с сохранением уже открытых соединений. Если изменение нельзя безопасно применить на работающем ядре, оно возвращает явную ошибку; автоматического общего перезапуска нет.
- Расход по отдельным портам отображается без потери точности больших счётчиков. Недоступные или устаревшие данные не подменяются нулями.
- Исправлена обработка конфликтов при создании ноды. Ошибки фонового уведомления после сохранения не выдаются за неудачное создание.

### Автономная работа и лимиты

- Нода сохраняет выделенные резервы квот и неподтверждённый расход. Временная недоступность панели не обнуляет состояние.
- Сброс квоты применяется к доступным нодам сразу; остальные получают его после подключения. Пока действует старый резерв недоступной ноды, общий расход может временно превысить новую квоту.
- Отзыв устройства учитывает соединения в прежних конфигурациях порта, сохраняя доступ остальных устройств.
- Исправлена гонка чтения и освобождения буферов mKCP.

### Обновление

- Установщик и агент обновления сохраняют состояние ноды и параметры Compose. Очистка старых образов сохраняет используемые образы и предусмотренную версию для отката.
- Встроенные вспомогательные файлы установщика проверяются как единый набор по контрольным суммам.
- Добавлены миграции для очереди применения резервов и назначения нескольких портов одному inbound.
- Документация и таблица совместимости согласованы с версиями компонентов.

### Официальная основа

Remnawave 3.4.5, Remnawave Node 3.4.2, Subscription Page 8.0.0. Ядро основано на официальном теге Xray v26.10.10, который upstream помечает как предварительный выпуск; произвольные изменения из main не включены.

### Границы совместимости

Независимые профили требуют согласованных версий панели, ноды и ядра из этого выпуска. Переход с прежней единой конфигурации не объявляется бесшовным. Не все изменения транспорта допускают применение без перезапуска. Интеграции с реальными внешними IdP, passkey и полный нагрузочный E2E всех операций не подтверждены этим выпуском.

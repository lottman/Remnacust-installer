# 1.2.108

Комплект панели и страницы подписки **1.1.7.72**, ноды **1.1.19**, Core **1.1.11**.

- При установке и переносе страницы подписки можно указать другую HTTPS-панель и её API-токен с правами страницы. Локальная панель сохраняет автоматическую выдачу ограниченного токена.
- В управлении страницей добавлен пункт 9 «Сменить панель и API-токен» и команда `configure-subscription-page`. Токен вводится скрыто либо передаётся приватным файлом 0600 через `--panel-token-file`.
- До применения проверяются версия панели и доступ к конфигурациям страницы. Редиректы не передают токен на другой адрес. Неверный токен не меняет настройки; ошибка готовности восстанавливает прежние Compose и окружение.
- Меняется только выбранная страница; общий env-файл других сервисов не переписывается. Остановленная страница остаётся остановленной, версия образа и публичный домен при смене подключения сохраняются.
- Уже наш образ `ghcr.io/lottman/remnacust-subscription-page` исключён из предложений повторного переноса. Официальная страница в проекте с именем Remnacust по-прежнему может быть перенесена.
- В панели исправлены обычные кнопки сохранения и подпись загрузки; документация синхронизирована на четырёх языках.

Новых миграций БД нет. Нода и Core закреплены за прежними выпущенными версиями. Готовые образы amd64/arm64 публикуются после успешных CI, проверок исходников и файлов выпуска.

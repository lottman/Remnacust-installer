# 1.2.149

Согласованный комплект: Panel/Subscription Page **1.1.7.103**, Node **1.1.27**, Core/WASM **1.1.17** на основе **Xray v26.11.9**.

Адрес подписочного DAT меняется вместе с содержимым файла: клиент получает новую ссылку после обновления подписки. Исправлены JSON на базовом адресе для совместимого Throne и при явном `/json`. Добавлены режимы основного домена: свободный доступ, только через CDN и перенаправление на выбранный CDN. Для закрытого origin используются отдельные подписанные значения заголовка каждого CDN; прежние публичные селекторы не являются подтверждением доступа.

В Core перенесены runtime-изменения Xray v26.11.9. Новые слоты XDRIVE включаются через `useSlots`; прежний формат остаётся значением по умолчанию. Редактор использует согласованные custom/default WASM и схемы. Обновление панели не обновляет удалённые ноды автоматически.

Уязвимость CVE-2026-98432 относится к ядру Linux. Отключённый по умолчанию MPTCP в Xray не заменяет исправленное ядро и его загрузку. Установщик не перезагружает сервер автоматически.

## English

Pinned bundle: Panel/Page **1.1.7.103**, Node **1.1.27**, Core/WASM **1.1.17**, based on **Xray v26.11.9**. Updated DAT content gets a new signed subscription URL. JSON delivery supports explicit `/json` and compatible Throne releases; primary-domain access can remain open, require CDN proof or redirect to a selected CDN. Each CDN has separate signed origin headers.

XDRIVE slots are opt-in with `useSlots`; the previous wire format stays the default. Updating Panel does not automatically update remote nodes. CVE-2026-98432 requires a patched Linux kernel; Xray's MPTCP default is only a mitigation. No automatic server reboot is performed.

Separate publishing from administration

A content change should not need unrestricted server access. Keep deployment credentials scoped to their job and remove unused access.

Know the recovery path

Write down where the files and data live, how a backup is made and how long a restore takes. A backup that has never been restored is an assumption.

Measure the real workload

Traffic and storage estimates help choose a starting point. They do not predict peak concurrency, CPU demand or database latency. Test the actual application before relying on a capacity claim.

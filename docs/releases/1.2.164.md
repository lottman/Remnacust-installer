# Remnacust Installer 1.2.164

- Комплект: Panel/Page 1.1.7.116, Node 1.1.31, Core 1.1.19 / Xray v26.11.9.
- Оба встроенных ядра ноды собираются на Go 1.27.4 для устранения GO-2026-6859. Обычный Xray собирается из закреплённого официального исходника с проверкой SHA256. Удалённые ноды и отдельно закреплённые managed-ядра требуют отдельного обновления.
- После публикации и анонимной проверки стабильного выпуска latest у всех трёх Docker-образов переводится на проверенный комплект. Старый выпуск или prerelease не может заменить latest.
- Исправления панели: сохранение блокировки HWID без ложной ошибки доставки, восстановление явно остановленного ядра при недоступной статистике, очистка предпросмотра, плавное закрытие окон и точные сроки подписки. Настройки установленной панели не меняются.

## English

Pins Panel/Page 1.1.7.116, Node 1.1.31 and Core 1.1.19 / Xray v26.11.9. Both bundled cores use Go 1.27.4 to address GO-2026-6859; ordinary Xray is built from pinned official source with SHA256 verification. Remote nodes and independently pinned managed cores require separate updates.

After anonymous verification of the published stable installer, all three latest image aliases move to the verified bundle. Older releases and prereleases cannot replace latest. Includes the panel fixes for durable HWID changes, stopped-core recovery, preview cleanup, modal transitions and precise expiry presentation without altering installed panel settings.

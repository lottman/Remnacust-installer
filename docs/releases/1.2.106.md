# 1.2.106

Комплект панели и страницы подписки **1.1.7.70**: автоматический выбор встроенных правил или загрузки геофайлов по размеру каждого профиля, название профиля из подписки, сохранение действий и интервалов. Хосты не суммируются для сравнения с лимитом отдельной конфигурации INCY. Обновите отдельно установленную страницу вместе с панелью, затем обновите подписку в приложении.

Исправлен обрыв DAT больше 16 MiB на странице подписки: отдельный предел DAT — 64 MiB. Исправлено сохранение старых значений после массового изменения хостов: свежие данные при открытии и отправка только изменённых полей. Параллельные запросы одного DAT используют одну сборку.

Логика установщика, нода **1.1.19** и Core **1.1.11** не меняются. Закреплены новые исходники панели и образы amd64/arm64. Новых миграций нет.

Версии 1.1.7.69 / 1.2.105 не публиковались в Stable: независимая проверка обнаружила и закрыла дополнительный сбой общего счётчика сложности профилей перед выпуском 1.1.7.70 / 1.2.106.

# 1.2.135

- Закреплены панель и страница подписки 1.1.7.96: отдельные соединения загрузки геофайлов, пакетная запись квот и накопленного трафика, согласованная подготовка смешанного парка нод.
- Исправлены сравнения срока и снимков устройств в UTC. Миграция функций доступа не меняет сохранённые даты пользователей, остаток заморозки и квоты. Новых переменных `.env` нет.
- Из найденных участков журналирования убран вывод секретов. Обновлены интерфейс тегов и документация панели на четырёх языках.
- Node 1.1.22 и Core 1.1.13 сохранены. Обновление панели не заменяет удалённые ноды. Для исправленной выдачи геофайлов обновите панель и страницу подписки.

Выпуск содержит готовые Docker-образы панели, ноды и страницы для Linux amd64/arm64, контрольные суммы и комплект установщика с закреплёнными исходниками.

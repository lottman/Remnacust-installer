# 1.2.156

Комплект: Panel/Page **1.1.7.110**, Node **1.1.28**, Core/WASM **1.1.17** на Xray **26.11.9**.

- Пустой IP панели не создаёт правил доступа при установке, переносе, смене режима сайта или выпуске/продлении сертификата. Старые управляемые renewal-хуки отсоединяются и при сохранении TLS.
- Удаление ноды снимает принадлежащую ей nftables-таблицу, точные управляемые UFW-профили и распознанные служебные файлы. Чужие/изменённые правила сохраняются. Принадлежность проверяется до изменений; общий lock сохраняет стабильный inode.
- Общая защита от понижения версии сверяет реестр, Compose и точные OCI-метки контейнеров до изменения конфигурации. Перенос штатного Remnawave и перенастройка подключения страницы сохраняются.
- Сохранён мастер переноса страницы подписки с заполненными данными. Страница и панель обновляются отдельно.
- В комплект включены исправления категорий DAT, безопасные подсказки хостов и настройка порога 1–250 000 с независимыми защитными бюджетами.

## English

Bundle: Panel/Page **1.1.7.110**, Node **1.1.28**, Core/WASM **1.1.17** on Xray **26.11.9**. An empty panel IP creates no managed firewall rules, including migration, website changes and certificate renewal. Cleanup verifies installation ownership, preserves unrelated rules and keeps the lock inode stable. Shared downgrade protection checks registry, Compose and exact container metadata before mutation while retaining upstream migration and page connection reconfiguration. Existing subscription-page migration remains available. Update separately hosted pages as well as the panel; keep secrets and backups unchanged.

# 1.2.155

Комплект Panel/Page 1.1.7.109, Node 1.1.27, Core/WASM 1.1.17.

- Порог обычных правил настраивается в разделе «Геофайлы»: 1–50 000 адресов/условий, по умолчанию 20 000. Независимые ограничения размера сохраняются.
- Кэш проверок категорий удалённых файлов отделён от готовых правил: проверки больше не вызывают повторную компиляцию востребованных наборов.
- Кэш компиляции правил ограничен числом условий, объёмом текста и количеством наборов; востребованные данные сохраняются по LRU. Параллельные запросы используют общую компиляцию.
- При выключенной автоматизации сохраняются явно прописанные администратором Xray-геоданные и routing; назначения библиотеки не обрабатываются.
- Публикация не меняет настройки установленного сервера. Нода, ядро и команды установщика не изменялись.

## English

Bundle: Panel/Page 1.1.7.109, Node 1.1.27, Core/WASM 1.1.17.

- Configure the shared inline threshold under Geofiles: 1–50,000 addresses/conditions, default 20,000. Independent size limits remain.
- Compiled rules use a bounded LRU cache with text-byte, matcher-count and entry limits. Concurrent requests share compilation.
- Disabling automation preserves explicit manual Xray geodata and routing while bypassing managed library assignments.
- Publishing does not change any installed server. Node/Core and installer commands are unchanged.

# 1.2.115

- Панель и страница подписки 1.1.7.79: автоматические CDN-ссылки с ID домена в пути. Подписка, геофайлы, контрольные суммы и персональные ссылки устройств сохраняют CDN-адрес при Host основного сайта на источнике.
- В панели есть окно настройки CDN с источником HTTPS, Host/SNI и локальным преобразованием старой ссылки или ключа. API и карточка пользователя формируют новый адрес автоматически; отдельный поддомен источника и переписывание пути не нужны.
- Старые ссылки остаются доступными. Для автоматического определения CDN с подменой Host замените URL в приложении один раз. Обновляйте панель и отдельно установленную страницу вместе; текущая зарегистрированная локальная страница обновляется штатно.
- Сборка проверяет готовые образы панели и страницы совместно: ограниченный токен страницы, подмена Host источника, JSON, HTML/QR, загрузка геофайла, старые ссылки и неизвестные ID. Управление доменами остаётся защищено прежними правами; публичный resolver возвращает только публичный адрес CDN.
- RU/EN/FA/ZH и документация обновлены. Новых миграций и переменных .env нет. Нода 1.1.19 и Core 1.1.11 прежние.

# Remnacust Installer 1.2.165

- Комплект: Panel/Page 1.1.7.117, Node 1.1.31, Core 1.1.19 / Xray v26.11.9.
- Панель сохраняет заморозку без ложной ошибки A039. Для новой заморозки обязательна дата автоматической активации; после сохранения она неизменяема. После простоя срок продолжается от назначенной даты, без добавления времени простоя.
- Доставка доступа на ноды проверяет актуальные права и ключи, обрабатывает отрицательное подтверждение и повторяет незавершённые изменения. Права API-токенов не расширяются. Переводы ошибок и справка обновлены на четырёх языках.
- Обновление панели применяет миграции 203 и 204 без удаления пользователей или настроек. Старые замороженные записи без даты сохраняются; дату можно назначить один раз. Удалённые ноды обновляются отдельно.
- Сохранены сборка обоих ядер на Go 1.27.4 и проверка стабильного latest всех Docker-образов перед продвижением комплекта.

## English

Pins Panel/Page 1.1.7.117, Node 1.1.31 and Core 1.1.19 / Xray v26.11.9. New freezes require a future automatic activation deadline, immutable after saving. After downtime, lifetime continues from the scheduled deadline. Saved freezes no longer fail because a node is offline; queued access changes validate current authorization and retry failures. API-token scopes are not expanded. Panel migrations 203 and 204 retain users and settings; legacy freezes without a deadline remain unchanged until a date is assigned once or the administrator activates them. Remote nodes require separate updates. Both bundled cores retain Go 1.27.4; latest image promotion requires a verified stable image cohort.

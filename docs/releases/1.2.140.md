# 1.2.140

Согласованный комплект: Panel/Page **1.1.7.101**, Node **1.1.26**, Core/WASM **1.1.16** на основе Xray v26.10.31.

- В комплект включены исправление выдачи подписки с HWID без ожидания нод, общий выбор custom/default Xray, два ядра Node и соответствующие валидаторы редактора.
- Обновлены стабильные зависимости и среда сборки. Образы amd64 и arm64 собираются и проверяются отдельно.
- Команда установки не закрепляет номер: установщик разрешает Latest в точный выпуск и проверяет его манифест и контрольные суммы.
- Установщик не меняет major-версию PostgreSQL существующего сервера автоматически. Постоянные данные и журналы квот сохраняются; несовместимые функции не обходятся удалением данных.

Документация панели содержит инструкции переключения Xray, совместимости старых нод, HWID и миграций. Публикация комплекта сама по себе не обновляет установленные серверы.

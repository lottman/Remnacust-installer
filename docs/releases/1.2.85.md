# 1.2.85

Панель и страница подписки 1.1.7.50. Нода 1.1.18 и Core/WASM 1.1.11 остаются прежними. Новых миграций БД нет.

- «Загружать клиенту» доступно для Xray JSON. Happ и INCY с поддержкой профилей из подписки получают подписанные GeoIP/GeoSite DAT и профиль первоначальной загрузки. Несколько файлов объединяются с отдельными именами категорий, без смешивания одинаковых категорий из разных источников. DIRECT, REJECT, прокси и балансеры остаются в полной конфигурации.
- Для INCY добавлены контрольные суммы SHA-256 и `routing-geo-update-interval`. Общий профиль использует наибольший интервал прикреплённых файлов, округлённый вверх до целых часов, минимум один час. Локальные настройки приложения приоритетнее. Для Happ интервал задаёт метку ревизии при обновлении подписки; фактические загрузки и повторы выполняет приложение.
- Остальные Xray JSON-клиенты получают встроенные правила. Ручной routing и имеющиеся geodata не перезаписываются; при конфликте, слишком большом профиле или отказе сборки весь ответ возвращается к встроенным правилам. Подготовленные данные одного клиента не используются для другого.
- Подписанные ссылки и SHA-256 выдаются также через страницу подписки. Проверяются состав набора, типы и ID файлов; удалённые файлы не выдаются из кеша. Ограничены размер, сложность, параллельные сборки и память кеша. Неисправное обновление источника сохраняет последнюю рабочую версию.
- Исправлено выравнивание значка GitHub в окне версий. Обновлены описания, встроенная справка RU/EN/FA/ZH и документация совместимости. Проверен мобильный экран 320 px, светлая тема и RTL.

Локальные проверки: 655 backend-тестов прошли, четыре платформенных теста пропущены в Windows; 223 frontend-теста прошли. Проверены типы, сборки, HTTP-передача через страницу подписки, подписи и контрольные суммы. Двенадцать вариантов нативных и встроенных правил DIRECT/REJECT/балансер приняты опубликованным ядром 1.1.11. Испытание всех сторонних приложений на физических устройствах не заявляется. Публикация дополнительно проверяет Linux CI, готовые образы amd64/arm64 и контрольные суммы файлов выпуска.

Обновление: `sudo remnacust upgrade-panel --version 1.2.85`. Сохраните шаблон и обновите полную JSON/YAML-подписку. Для Happ/INCY выберите Xray JSON в Response Rules либо включите выдачу JSON на основном URL для поддерживаемых клиентов. После обновления переподключитесь. Одиночная ссылка VLESS и URI/Base64-подписка не переносят произвольную маршрутизацию и geofiles; универсального скрытого механизма загрузки для всех приложений нет.

Основания совместимости: [INCY Routing](https://docs.incy.cc/en/routing/), [INCY full Xray configs](https://docs.incy.cc/en/full-xray-config/), [Happ Routing](https://github.com/HappDev/happ_su/blob/main/dev-docs/routing.md), [документация geofiles панели](https://github.com/lottman/Remnacust-panel/blob/main/docs/GEOFILES.md).

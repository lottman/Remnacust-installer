# 1.2.137

- Установщик поддерживает Debian 12 (bookworm) и Debian 13 (trixie) наряду с Ubuntu 22.04/24.04/26.04 LTS. Для установки Docker выбирается официальный репозиторий своей ОС; существующий Docker сохраняется. Проверки userspace не заменяют испытание загрузки ОС или отдельную проверку arm64.
- Панель: ускорены SQL-поиски квот HOST/TAG и повторные запросы подписок, добавлена диагностика PostgreSQL для администратора с ограниченным временем выполнения и кешированием. Решения доступа и учёт квот сохранены.
- Нода: исправлены восстановление сохранённого Core и работа при недоступной панели, ограничены ожидания управления процессом; проверки совместимости сохраняют защиту автономных квот и состояния учёта.
- Core: исправлены очистка ресурсов Xera HTTP и обработка повторных mux-сессий, усилены проверки повторного применения резервов квот, обновлены зависимости безопасности.
- Обновлены документация совместимости, описание API-прав и восстановления редакторов. Обновление панели не заменяет удалённые ноды; установленный управляемый Core проверяйте отдельно.

Обновляйте нужные компоненты отдельно с сохранением `.env`, `APP_SECRET`, состояния ноды и резервной копии БД. Установщик сохраняет major-версию PostgreSQL; смена major требует отдельного переноса данных.

# 1.2.138

- Комплект: панель и сайт подписки 1.1.7.99, Node 1.1.24, Core 1.1.15 / Xray v26.10.31. Компоненты обновляются отдельно; обновление панели не заменяет удалённые ноды и ранее выбранное управляемое Core.
- `--check-release` проверяет выпуск без APT и установки компонентов. Доступные системные пакеты, включая новое ядро, больше не блокируют проверку выпуска кодом `75`.
- Фоновое обновление панели через её локальный update-agent на подготовленном сервере обновляет приложение, а обслуживание ОС откладывает до SSH с записью в журнале. Недостающие системные зависимости по-прежнему могут потребовать SSH; отложенное обслуживание не означает, что ОС обновлена.
- Интерактивный CLI сохраняет `apt-get update` и `apt-get upgrade -y --with-new-pkgs`. Настоящие вопросы dpkg/debconf решает оператор; `--yes` не выбирает настройки пакетов. Автоматической перезагрузки, autoremove или принудительной замены конфигурации нет.
- Для уже установленного 1.2.137 требуется разовое обновление установленного installer/update-agent новым проверенным скриптом через SSH. Старый agent вызывает старый CLI до загрузки нового entry script; публикация 1.2.138 сама по себе не исправляет уже работающий daemon. После разового обновления повторите операцию из панели.

Перед обновлением сохраните `.env`, `APP_SECRET`, состояние ноды и резервную копию БД. Опубликованные теги и assets предыдущих выпусков не заменяются.

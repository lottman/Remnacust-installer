# 1.2.87

Панель и страница подписки 1.1.7.52. Нода 1.1.18 и Core/WASM 1.1.11 без изменений. Новых миграций БД нет.

- Добавлена стратегия «По приоритету: первый доступный». Клиент использует первый работающий сервер; при его отказе — второй, затем третий. После восстановления основного новые соединения возвращаются на него. Переключение зависит от интервала проверок доступности; уже открытые соединения не переносятся.
- Для точного порядка выберите «Хосты» и «Все выбранные хосты», затем переставьте участников стрелками. Порядок префиксов нескольких пулов также редактируется. GUI и код работают с одним шаблоном. Теги и regex используют общий порядок хостов, случайные режимы сначала выбирают подмножество.
- В Xray JSON намерение priority при выдаче преобразуется в стандартные балансеры leastPing с одним кандидатом и цепочку Loopback. Обновление ядра не требуется. До первой успешной проверки и при отказе всех участников соединения блокируются; явно указанный fallbackTag используется последним. GUI удаляет автоматически заданный резерв на тот же пул, сохраняя собственный резерв и параметры проверок.
- В Mihomo/Clash/Stash используется native fallback. Явные участники из кода идут перед динамическим пулом. sing-box не поддерживает автоматический строгий приоритет в конфигурации: selector остаётся ручным, URLTest выбирает по задержке. Эти ограничения объяснены в интерфейсе.
- Сохранены ограничения доступа, видимость и исключения хостов. Цепочки ограничены 128 участниками на балансер и 256 на конфигурацию. Несовместимые routing script, конфликтующие селекторы и некорректные резервы отклоняются. Незавершённые настройки можно сохранить как черновик с предупреждением.
- Обновлены документация и локализация RU/EN/FA/ZH. Проверены мобильный экран 320 px, темы, RTL, клавиатура и сохранение порядка. Кнопки перестановки имеют размер 44 × 44 px.

Проверки: 666 серверных и 227 интерфейсных тестов прошли; четыре платформенных теста пропущены в Windows. Проверены типы, линтеры и production-сборки панели. На опубликованных официальном Xray 26.10.21 и Remnacust Core 1.1.11 выполнены реальные подключения через три локальных прокси: основной, отказ первого и второго, восстановление основного и блокировка при отказе всех. Проверено по 60 соединений на каждом ядре, прямого обхода не было. Нативные генераторы Mihomo/Clash проверены тестами. Проверка интерфейса использует тестовый API; физические приложения Happ/INCY не запускались.

Обновление: `sudo remnacust upgrade-panel --version 1.2.87`. Отдельно установленную страницу подписки также обновите. Выберите стратегию приоритета в шаблоне, сохраните и обновите полную JSON/YAML-подписку в приложении. Последующее переключение выполняет клиент без повторного получения подписки.

Подробности: [документация](https://github.com/lottman/Remnacust-panel/blob/main/docs/GEOFILES.md#приоритет-серверов-11752), [Xray Loopback](https://xtls.github.io/en/config/outbounds/loopback.html), [Mihomo fallback](https://wiki.metacubex.one/en/config/proxy-groups/fallback/), [sing-box selector](https://sing-box.sagernet.org/configuration/outbound/selector/).

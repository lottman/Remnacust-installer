# 1.2.147

- Исправлена первая настройка TLS/XHTTP после переноса ноды: установщик больше не запрашивает состояние Nginx до добавления этого сервиса в Compose. Ключи, API-порт, рабочая конфигурация и данные ноды сохраняются.
- Домен, подтверждённый при настройке TLS ноды, повторно не спрашивается перед проверкой выпуска. Домен из параметра командной строки по-прежнему подтверждается один раз.
- При HTTP-01 активный UFW временно отключается и восстанавливается после Certbot при установке, переносе и смене домена. Сохраняется аварийное восстановление при прерывании; выключенный UFW не включается. DNS-01 не требует отключения UFW.
- При ошибке сертификата показывается путь к журналу ACME. Общая ошибка Docker указывает операцию, код завершения и безопасное описание причины без вывода ключей и переменных окружения.
- Проверен вопрос NET_ADMIN при переносе: согласие добавляет право в новую конфигурацию, уже действующее право сохраняется.

Для HTTP-01 TCP 80 должен быть доступен также в firewall провайдера и внешних сетевых фильтрах. Установщик не изменяет их настройки. Автоматическая перезагрузка сервера не выполняется.

Версии компонентов: Panel/Subscription Page 1.1.7.100, Node 1.1.26, Core 1.1.16.

# 1.2.146

- Перенос ноды Remnawave предлагает настройку сайта, TLS/XHTTP и сертификата. Существующие ключ, API-порт, профиль Xray и данные сохраняются; уже настроенный TLS можно оставить.
- Настройка дополнительного TLS выполняется после переноса. При её ошибке перенесённая нода не удаляется; настройки сайта и сертификата защищены откатом.
- Nginx использует тот же сохранённый каталог сокетов, что и нода. Пользовательский сайт сохраняется, для нового сайта выбирается один из встроенных вариантов.
- NeedRestart выводит список ожидающих перезапуска служб вместо несовместимого интерактивного режима Ubuntu. Вопросы dpkg доступны в терминале; автоматической перезагрузки нет.
- Публичная команда использует один самодостаточный `Install.sh`, включая запуск через `bash <(curl …)`. Отдельный `bootstrap.sh` удалён.

Версии компонентов сохранены: Panel/Subscription Page 1.1.7.100, Node 1.1.26, Core 1.1.16. Обработка сбоев GitHub 504 не изменена.

- Для перенесённого каталога сокетов Nginx получает только право прохода (711). Перед этим проверяется, что служебные файлы закрыты (600), вложенные каталоги закрыты (700), а путь не подменён. При откате возвращаются исходные права.

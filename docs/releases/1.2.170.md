# 1.2.170

- Согласованный комплект Panel/Page 1.1.7.122, Node 1.1.33, Core 1.1.19 / Xray 26.11.9.
- Установка, обновление и перенос панели поддерживают `--panel-ipv6 auto|on|off`. По умолчанию auto проверяет условия и сохраняет прежние сети при несовместимости; on останавливается с объяснением до изменения Compose; off удаляет подключения к собственной egress-сети.
- Отдельная IPv6-only NAT-сеть подключается ко всем приложениям панели, включая обработчики очередей и планировщик. БД, кеш, proxy, Node и сайт подписки сохраняют прежние подключения и порты.
- Проверяются маршрут хоста, отключающие sysctl, RA, версии Engine/Compose, NAT и принадлежность существующей сети. Глобальные настройки Docker/sysctl не перезаписываются. Требуются Docker Engine 28+ и Compose 2.33.1+; RA может требовать предварительного `accept_ra=2` на соответствующем интерфейсе.
- Собраны самодостаточные Install.sh/installer.sh и проверяемый helper-комплект. Ошибка изменения прав временного файла закрывает дескриптор и сохраняет исходный файл.

## English

- Cohort: Panel/Page 1.1.7.122, Node 1.1.33, Core 1.1.19 / Xray 26.11.9.
- Panel install, upgrade and migration accept `--panel-ipv6 auto|on|off`. Auto preserves existing networking when checks fail; on reports the problem before modifying Compose; off removes owned egress attachments.
- A dedicated IPv6-only NAT network serves panel API, queue processors and scheduler. Database, cache, proxy, Node and subscription-page connections and published ports remain intact.
- Checks cover host routes, disabling sysctls, RA, Engine/Compose versions, NAT and existing network ownership. Global Docker/sysctl settings are not overwritten. Engine 28+ and Compose 2.33.1+ are required; RA may need prior per-interface `accept_ra=2` configuration.
- Rebuilt standalone installers and their verified helper cohort. Temporary-file permission failures close the descriptor and preserve the original file.

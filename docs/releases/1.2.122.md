# 1.2.122

- Панель и страница подписки 1.1.7.86: устранены дубли DIRECT/REJECT, действия согласованы с профилем клиента. Встроенные правила ограничены 20 000 условиями на профиль; для Happ/INCY действует дополнительный порог 90 000 байт с учётом форматирования. При превышении выдаются DAT только с выбранными категориями. Профили разных хостов не суммируются.
- Сохранены подписанные старые ссылки и стабильные профили. Обработка временных ошибок источника больше не создаёт кешируемый 404; незавершённые соединения закрываются. Документация и интерфейс обновлены на RU/EN/FA/中文.
- Новые Caddy-службы панели и отдельной страницы подписки используют `GODEBUG=multipathtcp=0`. Существующий общий proxy не перенастраивается и не перезапускается. Проверки создания конфигурации не меняют sysctl или ядро хоста.
- Node 1.1.20 и Core 1.1.12 на стабильном Xray v26.10.31 сохранены. Новых миграций БД и переменных панели `.env` нет. Служебный комплект установщика пересобран с проверкой хешей.

CVE-2026-98432 относится к ядру Linux. Выключение MPTCP снижает поверхность атаки; полное исправление требует обновлённого и загруженного ядра. Установщик не подменяет эту проверку обновлением контейнера. [Объяснение Go Security Team](https://groups.google.com/g/golang-announce/c/PCoQcdxoScw/m/aD-MgXEvAAAJ).

Для применения исправлений выдачи обновите панель и страницу подписки согласованным комплектом, затем обновите подписку в клиенте. Публикация выпуска сама по себе не устанавливает его на рабочие серверы.

# 1.2.113

- Панель и страница подписки 1.1.7.77: синхронизация основного домена с `SUB_PUBLIC_DOMAIN` в `.env` в обе стороны, импорт HTTPS URL и адресов с путём, проверка при запуске API и каждые 30 секунд.
- Локальная служба получила узкую операцию чтения/записи только основного домена. Приватный сокет и HMAC, ограниченные запросы, проверка ревизий и блокировки, защита от ссылок и нештатных файлов. Секреты и прочие переменные не выдаются и не заменяются.
- Значения переменной выравниваются в `.env` и приложениях зарегистрированного Compose без перезапуска. Копии хранятся в `backups/panel/subscription-domain-<id>/`. Параллельные изменения не затираются; повтор без изменений не создаёт новую копию.
- Вкладка страниц подписки следует за основными настройками. Общие иконки страниц и карточек используют акцент темы; домены доступны независимо от состояния службы страниц. Ошибки загрузки и сохранения разделены.
- Обновлены документация и RU/EN/FA/ZH. Новых миграций БД нет; нода 1.1.19 и Core 1.1.11 прежние. Неподтверждённая автономность нод по-прежнему не блокирует обновление панели.

Для синхронизации нужен этот установщик с его локальной службой. Сторонний YAML Compose требует нормализации зарегистрированной установки при обновлении. CDN-домены хранятся в реестре. DNS и сертификаты настраиваются отдельно.

# Remnacust Installer 1.2.162

- Комплект закрепляет Panel/Page 1.1.7.114 с исправлениями карточек хостов, подсказок редактора, схемы remnacust и переключения стратегий автовыбора.
- Очистка после успешного обновления распознаёт старые local/remnacust-* образы только с подтверждённой меткой проекта. Используемые любыми контейнерами, текущий и предыдущий образы сохраняются; чужие ссылки, тома и резервные копии не удаляются.
- Самодостаточная точка входа Install.sh и встроенный комплект помощников синхронизированы и проверены.
- Node 1.1.30 и Core 1.1.18 / Xray 26.11.9 остаются без изменений. Обновление панели не обновляет удалённые ноды автоматически.

## English

Pins Panel/Page 1.1.7.114 with host-card reopening, readable localized host previews, remnacust schema support and correct strategy setting cleanup. Image cleanup recognizes verified local project builds while protecting current/previous and container-referenced images. Foreign aliases, volumes and backups are preserved. The standalone Install.sh and verified helper bundle are synchronized. Node 1.1.30 and Core 1.1.18 / Xray 26.11.9 are unchanged.

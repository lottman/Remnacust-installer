# 1.2.67

Убрана отдельная кнопка «Обновить ноды» в обзоре сессий. Теперь «Начать обход» сначала загружает актуальный список нод и затем опрашивает доступные. Повторный обход тоже обновляет список. После ошибки загрузки или пустого списка можно нажать ту же кнопку ещё раз; устаревшие данные не используются. Фоновый опрос каждые 5 секунд убран.

Исправлена ошибка `Unexpected non-whitespace character after JSON at position 4`, мешавшая применению профиля на нодах. Предупреждения Xray могли попадать перед служебным JSON-ответом. Теперь команды API выводят предупреждения отдельно в stderr, а ответ сохраняют в stdout. Предупреждения остаются видимыми в диагностике. Проверка воспроизводит прежний сбой, затем подтверждает корректный JSON и сохранение старого VLESS-соединения при применении нового профиля.

Компоненты: панель 1.1.7.37, нода 1.1.13, ядро 1.1.8. Браузерный валидатор и схемы обновлены до того же ядра. Новых миграций базы и изменений клиентских протоколов нет.

Для нового запуска обхода обновите панель. Для исправления ошибки применения профиля обновите также ноды до 1.1.13: вместе с образом установится исправленное ядро. Настройки профилей не требуется удалять или пересоздавать. Короткие подключения между опросами по-прежнему могут быть пропущены; список сессий не является историей всего трафика.

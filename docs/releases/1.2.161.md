# Remnacust Installer 1.2.161

Закреплён комплект Panel / Page 1.1.7.113, Node 1.1.30 и Core 1.1.18 / Xray v26.11.9. Команды установки и обновления, подтверждения, журналы, резервные копии и правила сохранения настроек не меняются. Самодостаточный `Install.sh` и внутренний `installer.sh` собраны из одного проверяемого набора помощников.

Панель исправляет создание пользователя после снятия запрета лимита HWID, сохраняет публичный домен в ссылке страницы подписки и улучшает поиск и чтение метаданных хостов. Нода исправляет первое применение обычного профиля после восстановления checkpoint; проверка новой конфигурации и восстановление прежней при ошибке обязательны. Это не разрешает произвольные перезапуски действующих профилей или обязательных live-планов. Обновляйте нужные компоненты отдельно: обновление панели не заменяет удалённые ноды.

## English

Pins Panel / Page 1.1.7.113, Node 1.1.30 and Core 1.1.18 / Xray v26.11.9. Installer commands, confirmations, private logs, backups and settings preservation remain unchanged. Both shell entry points contain the same verified helper cohort.

The panel fixes inherited HWID limits during user creation, public-domain subscription links, search presentation and host metadata lookup costs. The node fixes first ordinary profile application after checkpoint recovery with validation and checked rollback, without authorizing arbitrary restarts of acknowledged profiles or mandatory live plans. Update components separately; a panel update does not replace remote nodes.

В API пользователя предпочитается доступный CDN назначенного основного домена. Один основной домен допускает создание только одного CDN; старые дополнительные записи автоматически не удаляются. Домены, ключи, квоты и другие настройки сервера установщик не меняет.

The user API prefers the assigned primary domain’s available CDN. Each primary allows only one new CDN; existing additional records are not deleted automatically. The installer preserves server domains, credentials, quotas and other settings.

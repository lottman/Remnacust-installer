# 1.2.92

Исправление обновления с прежних установщиков. Панель и страница подписки остаются **1.1.7.57**, нода **1.1.19**, ядро **1.1.11**.

- Восстановлена совместимость проверяющего модуля 1.2.90 с новым комплектом помощников. Старый модуль требовал прежнее имя `stable_entry.py` и отклонял выпуск 1.2.91 на первом этапе с ошибкой `Incomplete helper cohort`. В архиве оставлен только инертный маркер этого имени: функция постоянного TCP-входа и команда её настройки не возвращаются.
- Добавлен тест с неизменённым модулем из опубликованного 1.2.90: проверка нового комплекта, контрольных сумм и подготовка автономного установщика выполняются старым кодом. Неполный комплект продолжает отклоняться.
- Ошибки Python и сети агента обновлений теперь сохраняются в закрытом техническом журнале на сервере. Подробности не передаются в публичный статус, а существующий чужой файл журнала не перезаписывается.

Обновление сохраняет прежние настройки. В панели выбирается версия панели 1.1.7.57; соответствующий готовый комплект установщика — 1.2.92. Если установка требует ещё не заданных параметров, их нужно уточнить перед повторным запуском, не подставляя случайные значения.

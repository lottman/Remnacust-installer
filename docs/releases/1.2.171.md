# 1.2.171

- Согласованный комплект Panel/Page 1.1.7.123, Node 1.1.34, Core 1.1.20 / официальный Xray 26.11.9.
- Перенос проверяет приватные каталоги, вложенные и именованные тома и защищённые переменные до остановки приложения. Исходное состояние запущенных и остановленных сервисов сохраняется. Откат не заменяет свежий журнал квот старой копией; незавершённый снимок ноды не скрывает данные её слоя контейнера.
- Node подтверждает конфигурацию после готовности приватного API Core. Запросы до синхронизации получают временный отказ без ложного подтверждения; восстановленное работающее ядро остаётся доступным для статистики. Проверяется фактический запуск с 2788 пользователями, отказ bind, восстановление и повторная синхронизация.
- Панель повторяет постановку конфигурации при её отсутствии и отличает временную неготовность статистики от потери связи. Начальный запуск включает сверку состояния нод.
- Xera освобождает отклонённые сессии, ограничивает заголовки HTTP/3 и согласует проверенный частичный профиль Chrome 155. Для соответствующих H2-профилей убран начальный рост TLS-записей; очередь ограничена и сохраняет обратное давление. Default packet-up: 20–40 мс со средней точкой 30 мс; явные настройки сохранены. Исправлено соблюдение явных TLS minVersion/maxVersion с uTLS.
- Редактор, схема и справка соответствуют Core 1.1.20. Изменения трафика не доказывают неотличимость от браузера или устойчивость к неизвестному классификатору. Для клиентских улучшений требуется соответствующее ядро клиента. Обновление панели не обновляет удалённые ноды; отдельно выбранное managed-ядро может оставаться закреплённым.
- Core исправляет освобождение сокетов TCP/WS/HTTP Upgrade и завершение фоновых операций XDRIVE. Graceful flush XDRIVE ограничен 30 секундами или более ранним write deadline; ошибка не подменяется успехом. Backend должен соблюдать отмену контекста.
- Новых миграций БД нет. Настройки, учётные данные, квоты и исходная версия PostgreSQL сохраняются. Выпуск не изменяет работающие серверы автоматически.

## English

- Matching Panel/Page 1.1.7.123, Node 1.1.34 and Core 1.1.20 / official Xray 26.11.9.
- Migration checks private directories, nested and named mounts and protected environment before stopping applications. Originally running and stopped services retain their state. Rollback preserves newer quota journals; an incomplete node snapshot does not hide container-layer state.
- Node acknowledges configuration after the private Core API is ready. Unsynchronized requests fail temporarily without false acknowledgements; restored running cores remain available for statistics. Verification covers 2788 users, bind failures, restoration and repeated synchronization.
- Panel retries missing configuration and distinguishes temporarily unavailable statistics from lost connectivity. Initial scheduling includes node state reconciliation.
- Xera releases rejected sessions, limits HTTP/3 headers and aligns a verified partial Chrome 155 profile. Matching H2 profiles remove the initial TLS record-size ramp through a bounded queue with backpressure. Default packet-up intervals vary from 20 to 40 ms around a 30 ms midpoint; explicit settings are preserved. Explicit uTLS minVersion/maxVersion bounds are now enforced.
- Editor, schema and documentation match Core 1.1.20. These changes do not establish browser indistinguishability or resistance to an unknown classifier. Client-side improvements require a matching client core. Updating Panel does not update remote nodes; separately selected managed cores can remain pinned.
- Core fixes TCP/WS/HTTP Upgrade socket cleanup and joins XDRIVE background operations. XDRIVE graceful flush has a 30-second budget or an earlier write deadline; failures are returned. Backends must honor context cancellation.
- No new database migrations. Settings, credentials, quotas and the existing PostgreSQL version are preserved. Publishing does not update running servers automatically.

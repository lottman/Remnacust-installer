# 1.2.79

Панель и страница подписки 1.1.7.45. Нода 1.1.17 и Core/WASM 1.1.11 остаются прежними. Миграций БД нет.

- Убрана декоративная иконка рядом с заголовком «Геофайлы». Новые вкладки автовыбора, геофайлов, истории и записи сессий используют общие карточки панели, цвета выбранной темы, отступы и скругления. Приведены к общему оформлению карточки лимитов и схем профилей.
- Поле выбора файла с ПК показывает «Нажмите, чтобы загрузить». Подсказка и каталог наборов переведены на RU/EN/FA/ZH.
- Добавлен каталог шести опубликованных DAT-наборов V2Fly и MetaCubeX: GeoIP, GeoSite, Private IP и GeoSite Lite. Источник виден до импорта. Загрузка проходит через существующий защищённый HTTPS-импорт с проверкой содержимого, DNS, переходов и размера. Совпадающие файлы повторно не хранятся.
- Импорт выбирает файл в общей библиотеке и сохраняет ручные поля формы. Правила не включаются автоматически: добавьте файл в шаблон, выберите категории и действие, затем сохраните шаблон. Наборы не обновляются в фоне; повторите импорт для получения новой версии.
- На телефоне форма записи сессий размещается в одну колонку. Кнопки новых форм имеют высоту не менее 44 px; сохранены RTL, клавиатурный фокус и цвета тем. Убрана отдельная анимация подъёма карточек схем.

Обновление: `sudo remnacust upgrade-panel --version 1.2.79`. Проверка интерфейса выполнена на изолированном стенде с настоящими компонентами и подменённым API; она не подтверждает доступность всех внешних файлов с каждого VPS. При настоящем импорте сервер выполняет проверки и сообщает об ошибке источника.

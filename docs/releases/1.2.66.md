# 1.2.66

В обзоре сессий список нод автоматически обновляется каждые 5 секунд. Добавлена отдельная кнопка «Обновить ноды» и показано, сколько нод доступно для обхода. Когда нода подключается, доступность запуска обновляется без перезагрузки страницы.

Загрузка, ошибка запроса, пустой список и отсутствие подключённых включённых нод теперь объясняются отдельно. Ошибка запроса не означает, что ноды отключены. Убрано устаревшее обязательное требование NET_ADMIN с экрана запуска: просмотр сессий этого права не требует. Уточнено описание: одновременно опрашивается не более 10 нод.

На установленной панели подтверждены четыре подключённые ноды. После полной загрузки страницы кнопка стала доступной; реальный обход завершился для всех четырёх нод. Точная причина прежнего состояния браузера не зафиксирована. Новые состояния интерфейса проверены тестами и кликом на локальном стенде. Проверки TypeScript, переводов и документации прошли.

Компоненты: панель 1.1.7.36, нода 1.1.12, ядро 1.1.7. Нода и ядро сохраняют код 1.2.64. Новых миграций базы нет. Для самого исправления кнопки достаточно обновить панель; исправления сбора IP из 1.2.64 требуют ноду 1.1.12 или новее и применения конфигурации панелью.

Установщик теперь сохраняет понятную причину отказа сертификата при разных кодах возврата OpenSSL: сертификат должен покрывать домен панели и все домены страницы подписки. Неверная пара не копируется, существующие файлы сохраняются. Добавлена проверка обоих вариантов поведения OpenSSL. Проверки TLS, страницы подписки и комплекта установщика прошли локально — 29 тестов.

Кандидат 1.2.65 не публиковался: проверка на другом выпуске Ubuntu выявила различие сообщений OpenSSL. Исправление включено в 1.2.66.

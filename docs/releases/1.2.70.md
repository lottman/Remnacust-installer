# 1.2.70

Убрано дополнительное переведённое пояснение над ошибкой Xray о смене порта или транспорта входящего подключения. В блоке «Последняя ошибка» остаётся исходная техническая диагностика с возможностью копирования. При создании ноды одинаковый исходный текст также не дублируется.

Компоненты: панель и страница подписки 1.1.7.40, нода 1.1.15, ядро 1.1.9. Для изменения интерфейса достаточно обновить панель. Поведение применения конфигураций и защита действующих соединений не изменены. Новых миграций нет.

# 1.2.168

Согласованный комплект: Panel/Page 1.1.7.120, Node 1.1.32, Core 1.1.19 / Xray 26.11.9.

Включает исправления закрытия окон, палитры редактора и порядка уведомлений, индикатор приближающейся оплаты нод. Node ограничивает gRPC-паузу переподключения к локальному API и ожидает завершения синхронизации пользователей. При ошибке синхронизации внутренний индекс остаётся заблокированным до успешного применения; работающий Xray сохраняется. Обновление панели само по себе не обновляет удалённые ноды.

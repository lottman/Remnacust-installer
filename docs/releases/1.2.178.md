# Installer 1.2.178

Согласованный комплект Panel/Page 1.1.7.135, Node 1.1.39, Core/WASM 1.1.22. Перенесены опубликованные Remnawave Backend/Frontend 3.4.11 и Node 3.4.6. Xray 26.11.9 и Subscription Page 8.0.1 остаются актуальными.

Панель включает хосты по именам правил ответа подписки, сохраняет порядок листьев и ограничивает «выбрать все» активным тегом. Авторизация больших запросов выполняется до разбора тела, с сохранением текущих прав и отзыва токенов. Новая миграция добавляет поле хоста без удаления данных.

Node поддерживает необязательные NFTABLES_TABLE_NAME и SUPPRESS_DUPLICATE_INSTANCE_WARNING. Подавление предупреждения не отключает обнаружение второго экземпляра. Сохранены Lua routing, собственное ядро и готовность управления.

Обновления панели, сайта подписки и ноды устанавливаются отдельно. Сохраните .env, ключи, APP_SECRET и постоянные каталоги. Миграции движутся вперёд; откат образа не требует отката базы.

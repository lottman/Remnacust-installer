# 1.2.103

Комплект панели и страницы подписки **1.1.7.67** исправляет ошибку размера конфигурации INCY iOS при встроенных геоправилах. Длинные списки выдаются в поддерживаемой Xray строковой форме без потери условий; учитывается повторное форматирование JSON клиентом. Выключенная загрузка геофайлов не включается автоматически.

После обновления панели и отдельно установленной страницы подписки обновите подписку в INCY. Нода **1.1.19** и Core **1.1.11** сохраняют прежние исходные коммиты. Логика установщика не меняется: выпуск содержит новый проверенный исходный коммит панели и соответствующие готовые образы amd64/arm64.
